## 二、退場（不要再拿出來上）

### ⚠️ 最重要的一份：`prompt_sample/Prompt_sampleUnit01.md`

那 20 組「壞 prompt → 爛回覆 / STRIKE prompt → 好回覆」的 A/B 對照表。

**不要再上這個單元。理由不是它做得不好，是對照組垮了。**

你把表格裡的「壞 prompt」（例：`幫我寫信給主管說報告要延期`）
丟給現在的模型，它**不會**回那句敷衍的話，它會給你一封像樣的信，甚至反問你原因。

```
台上會發生的事：
  講師：「大家看，壞 prompt 就會得到這種爛答案」
  學員：「可是我這邊跑出來的還不錯耶」
  → 對照組垮掉 → 整個單元的說服力歸零
```

而且這**每上一次課就更嚴重一次**。

> **新版的替代做法**：不比「單次好不好看」，比「10 次的通過率」。
> 見 `student_download/05_證明它有用/十題考卷_模板.md`。
>
> 這個對照組不會因為模型變強而失效，反而模型越強越好演。

## 五、如果你想把舊單元救回來

有兩個舊單元其實還有救，只要換掉對照方式：

| 舊單元 | 怎麼救 |
|---|---|
| **數據戰**（`D2` + `Analyze_sampleUnit03`） | 別比「好不好看」，改成建一份 5 題的數據問題考卷，比通過率。可當進階場的素材 |
| **簡報戰**（`D5`） | 同上。簡報的驗收標準特別難寫成 yes/no，**很適合當進階練習**（「一頁只講一件事」「每頁標題是結論不是主題」都是可核對的） |

> 但不要放進一天的基礎場 —— 時間不夠，而且會稀釋主線。
