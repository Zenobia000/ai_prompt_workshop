# 開課前檢查清單

這門課有五項是**每期都要重跑**的，不是備好一次就能用到退休。

原因很簡單：這門課教「你的資產會過期，要定期重測」，教材自己當然也適用。而且我們的教學內容有一半建立在實測數據上，那些數據會隨模型能力變動。

---

## 每期必做（開課前一週）

### 1. 重跑 Block A 的五個實驗

用你自己的一個真實問題，把 `A1_五個實驗_操作單.md` 從頭跑一次。

| 實驗 | 要確認什麼 | 上期結果 | 本期結果 |
|---|---|---|---|
| 一、同一題問三次 | 三次還有差異嗎 | | |
| 二、不給資料 | 它還會編嗎 | | |
| 三、effort 旋鈕 | 高低檔還有差嗎 | | |
| 四、三家工具 | 個性差異還在嗎 | | |
| 五、token 單價 | 當期價格 | | |

**任一項結論翻轉，那一段的講法要改。** 特別是實驗二：如果模型變得會老實說「我不知道」，這個實驗就不能當主打，要改用「資料不完整時它怎麼補」。

### 2. 重跑公版任務，確認分歧仍在

用三個不同的天真 prompt 跑 `公版任務/逐字稿A.md` 和 `逐字稿B.md`。

- [ ] 三份產出的**待辦數量仍有落差**（上一次實測是 9 / 8 / 7）
- [ ] 仍有產出漏掉「購物車五月底上線」
- [ ] 仍有產出把「請人去評估的方案」寫成決議

如果分歧消失了，**更新 `公版任務/三份真實產出_對照_A.md` 和 `_B.md`**，並把新的落差寫進講師手冊的 Block C 段落。

> 這兩份對照檔的用途是備援：全班產出剛好很像的時候直接拿出來。
> 所以它們必須是**當期**的實測資料，不能是去年的。

### 3. 自己跑一次消融實驗

拿範例 skill 跑 `D2` 的四種條件，確認結果符合預期（拿掉驗證塊掉最多）。

| 組 | 條件 | 本期分數 |
|---|---|---|
| 對照 | 三塊都在 | |
| A | 拿掉指示塊 | |
| B | 拿掉驗證塊 | |
| C | 拿掉範例塊 | |

**如果結果跟預期不同，不要改教材去迎合預期。** 改講師手冊的敘事：那一節真正教的是「去測，不要猜」，數據是什麼就講什麼。

### 4. 更新工具與價格附件

- [ ] 三家對話工具的介面有沒有改版
- [ ] effort / 思考模式的設定位置有沒有變
- [ ] 當期 token 價格
- [ ] `C4_工具安裝對照.md` 裡的三種裝法還成立嗎

### 5. 驗證所有 demo

- [ ] 開場要展示的範例 skill 打得開
- [ ] `B1` 的臃腫樣本 prompt 砍字後真的沒變差
- [ ] `B2` 的規格對照真的跑得出變異度差異

## 每期必做（開課前三天）

- [ ] 發出課前作業（`00_課前/課前準備單.md`），並強調 **Day 1 不用帶素材**
- [ ] 確認學員的 AI 工具能上傳檔案
- [ ] 確認人數不超過 16 人；超過就安排助教或拆場次
- [ ] 印心法卡

---

## Day 1 結束當天

- [ ] 寄出一週作業提醒信（`B3` 的內容重點）

## 中間那一週的第 4 天

- [ ] 寄第二次提醒。只問一句：「做第一次了嗎？」

**這封信的效果比你想的大。** Day 2 的出席率和產出品質，很大程度取決於這一週有沒有人推。

---

## 只要做一次的（首次開課前）

- [ ] 準備公版任務全套並自己跑過一遍
- [ ] 印製心法卡母版
- [ ] 建立 30 天回訪信的名單與樣板
- [ ] 招募助教並帶他跑一次 `C1` 的三個引出技法（那是助教主要的工作）

---

## 為什麼要做到這種程度

如果不重跑，最可能發生的事是：你在台上說「你看，AI 會編給你看」，然後全班的模型都老實回答「我不知道」。

那個場面救不回來，而且會連帶讓學員懷疑後面所有的內容。

舊版教材就是這樣垮的——「壞 prompt 得爛答案」的對照表，寫的時候是真的，一年後上台就變成假的。

**這份清單存在的理由，就是不要再發生第二次。**
