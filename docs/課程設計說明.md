# 課程設計說明（講師用）

這份不是講義，是設計理由書。

照著 `講師手冊.md` 就能上課。但如果現場要即興、要回答學員的刁鑽問題、要決定砍哪一段，你得知道每一段為什麼長這樣。

---

## 一、這門課的主軸

只有一句話：

> **把你腦中「認得出、但說不出」的品質判斷，變成別人和 AI 能照著執行的東西。**

用更短的說法：教「把品味變成規格」。

### 要翻轉的信念

學員進來的時候相信：

```
AI 做得不夠好 → 因為我 prompt 寫得不夠好 → 所以我要學怎麼寫
```

要讓他離開的時候相信：

```
AI 做得夠好了 → 不夠的是我從來沒說過「什麼樣才叫好」
```

### 技術核心只有一個動作

驗收檢核那條規則：**每一條都必須能用一句 yes/no 回答。**

```
「要夠專業」      → 你認得出，但說不出
「沒有出現口語詞」 → 你說出來了，別人可以照著做
```

**那個轉換的瞬間，就是這門課全部的內容。** 其他一切都是為它服務的鷹架。

## 二、為什麼是四個區塊

| 區塊 | 佔比 | 它在解決什麼 |
|---|---|---|
| A 認識這台機器 | 25% | 沒有這段，後面講驗收標準是空的 |
| B 提示詞作為設計 | 25% | 教框架，也證明它的天花板。真正產出是對話紀錄 |
| C 收成資產 | 35% | 課名所在，唯一帶得走的東西 |
| D 汰換與消融 | 15% | 回答「半年後還能不能用」，也是全課的收束 |

### Block A 為什麼不能砍

這是相對舊版新增的一整段，很容易被當成「暖身」砍掉。不行。

**理由**：這門課要學員把判斷寫給 AI 看。如果他不知道這台機器會在哪裡壞、為什麼同一句話問兩次結果不一樣、一次要花多少錢，那些判斷他會寫錯地方。

最具體的例子：不做實驗二（不給資料對給資料），學員就不會理解「要求它先列引用」為什麼重要，那條規則寫進 skill 也只是抄來的。

**設計上的關鍵**：五個實驗全部用學員**自己的同一題**，不是五個示範題。用同一題才比得出差異，而且填出來的體感表是他自己任務的。

### Block D 為什麼是收束不是附錄

學員從報名就想問「我今天花的時間會不會白費」。這一段正面回答它。

而且消融實驗的結果，**就是全課論點的證明**。老師不需要說服，數據會說：

```
拿掉「怎麼做」   → 分數幾乎不動
拿掉「怎麼算做好」 → 分數掉最多
```

方法論來自 Claude Code 團隊在 Opus 5 上線時砍掉自家 80% 系統提示的實踐。有出處，講起來有份量。

## 三、五個核心設計決定

### 決定一：全程只用一個範例

初學者最常在「每一段換一個例子」的課裡迷路。所以公版任務從頭到尾只有一個：會議逐字稿轉行動項。

選它的理由：人人都做過、產出好壞看得見、驗收標準不是常識但講出來就懂。

同時，學員用**自己帶來的任務**平行做一份。範例是拐杖，自己的任務才是成品。

> 不要用「摘要對行動項」當賣點。實測推翻了那個假設：
> 連「總結一下這場會議」都會產出七項含負責人與期限的待辦。
> 真正可靠的落差是**待辦數量 9 / 8 / 7，而最重要的交付有兩份漏掉**。

### 決定二：對比要架在「分歧」上，不是「錯誤」上

這是相對第一版最重要的修正。

第一版的教材押注在「素材的陷阱會讓模型出錯」。實測結果：

| 原設計的陷阱 | 實際觸發 |
|---|---|
| 決議被推翻 → 新舊並存 | 0/3 |
| 外部廠商負責人 → 填不出來 | 0/3 |
| 無結論 → 被寫成決議 | 1/3 |

**押注在「模型會出錯」上，跟舊版 STRIKE 的 A/B 演練是同一個賭注，而那正是舊版垮掉的原因。**

改押在同一批資料裡 100% 可重現的東西：三份產出的形狀完全不同、同一件事被歸到不同類別、相對日期沒有全部換算。

於是核心那句話從

```
「你看，AI 出錯了 → 所以要沉澱」
```

改成

```
「三份都對，但三份不一樣 → 所以要沉澱」
```

後者更強，而且不需要模型變笨。**模型越強，學員越無法用「換個更好的模型就好」迴避。**

### 決定三：收成優於創作

第一版要求學員從零寫驗收標準。批評自己：40 分鐘、冷開機、在自己的領域，多數人會寫出「要專業」。

新版改成從**對話紀錄**裡撿。

```
你跟 AI 說的每一句「不對，再短一點」「把負責人加上去」
        ↓
就是你的隱性標準當場被逼出來的那一刻
```

**學員不需要「想出」他的驗收標準，只需要回頭把自己罵過 AI 的話撿起來。**

這比創作低門檻太多，而且它就是「把說不出的說出來」最自然的形式——對話已經替他做完外顯化，他只是還沒去收。

> 這是整份教材門檻降最多的一步，也是兩段式結構存在的理由。

### 決定四：兩個半天，中間隔一週

不是排程方便，是結構性的。

這門課的核心是「第三次才沉澱」。一天課只能做到「第一次寫下來」，做不到「寫下來、拿去用、發現漏了、補回來」。

```
Day 1  產生原料  →  一週累積原料  →  Day 2 收成
```

兩段式順帶解決了兩個問題：

1. **課前作業回收率**。Day 1 完全不需要學員帶素材，最大的執行風險移到了 Day 1 之後，而那時候他已經上過課、知道為什麼要做
2. **Day 2 出席率變成 KPI**。它誠實反映「Day 1 有沒有讓他真的想回來」

### 決定五：不對初學者用工程詞彙

心法④的原型是抽函式（固定的寫死、變動的變參數、定義回傳值）。對工程師講三個字就懂，對初學者講會直接放棄。

全程用食譜：

| 工程說法 | 課堂說法 |
|---|---|
| 固定邏輯 | 步驟 |
| 參數 | 食材（每次換） |
| 回傳值型別 | **成品照**（做好長什麼樣） |
| 單元測試 | 考卷 |

比喻要一致到底。「成品照」這個詞特別重要，它讓「驗收標準」從抽象名詞變成學員能想像的東西。

## 四、每個區塊要打中什麼

| 區塊 | 表面在做 | 真正要打中的 |
|---|---|---|
| A | 五個實驗 | **物理直覺**。它會壞、它要錢、它不穩，而這些都是可預期的 |
| B | 框架與砍字 | **鬆一口氣**，你不用背東西。然後**撞牆**：規格不寫清楚，五次五種結果 |
| C | 做資料夾 | **手上有東西**，從抽象變成可以拖曳的實體 |
| D | 消融實驗 | **證據**。而且是他自己量出來的，不是老師講的 |

B 段的情緒設計是刻意的：先鬆一口氣，再撞一次牆。先鬆是因為初學者對 prompt 課有「又要背東西」的預期，要先拆掉；再撞是因為沒撞過牆的人不會覺得驗收標準重要。

---

## 五、心法八條的編組

第一版是七條，那是七單元結構的產物。改為四區塊之後，Block A（模型素養）和 Block D（消融）的心法沒被涵蓋。

現在是**每區塊兩條，共八條**：

```
A  ① 它是抽樣不是查表      ② 想知道它怎麼壞，把條件降下來
B  ③ 三問                 ④ 刪掉輸出不會變差的都是雜訊
C  ⑤ 只寫模型不知道的       ⑥ 把「認得出」寫成「說得出」
D  ⑦ 每條規則標保存期限     ⑧ 刪光再一行行加回來
```

**「食譜」和「第三次法則」被降級**，改成 Block C 操作單裡的工作規則，不佔心法名額。它們是好用的操作法，但不到心法的層級。

## 六、可裁切的版本

| 場次長度 | 上哪些 | 產出降級成 |
|---|---|---|
| **兩個半天（8h）** | A、B、C、D 全上 | 完整 skill、通過率、消融數據 |
| **一天壓縮版（6h）** | A（砍實驗四）、B、C、D 只講不做 | **skill 草稿**，沒有消融數據 |
| **半天體驗（3h）** | A ＋ B ＋ 展示做好的範例 skill | 模型體感表、一份對話紀錄 |

### 裁切的優先順序

砍的時候照這個順序：

1. 交棒測試（改成回家做）
2. Block A 實驗四（三家工具）
3. Block A 實驗五（算帳）
4. Block B 的砍字實驗

**永遠不要砍 C5 的考卷和 D2 的消融。** 砍掉那兩個，這門課就退化成「大家一起寫模板」的手工藝課，而且失去所有可量化的成果。

### 壓縮版必須誠實標示

一天版帶不走完整 skill，只帶得走草稿。行銷素材要寫清楚，不要超賣——40 分鐘寫不出一份能用的驗收檢核。

## 七、跟 M0–M9 工程課的關係

`archive/M0-M9_懶人包.md` 是另一門課（怎麼做出一套可控的 AI 系統）。兩門課承重的重疊只有四塊，但那四塊是這門課的地基：

| M0–M9 的 | 在這門課的哪裡 |
|---|---|
| M2「廢話是模型必須服從的雜訊」 | 心法④ 砍字，Block B |
| M2「刪掉 Model Rule、只留 Business Rule」 | 心法⑦ 保存期限，Block D |
| M7「二元判準、同一份 dataset 比對」 | C5 考卷 |
| M9「他會來問你＝你的判斷還沒收斂」 | D3 交棒測試 |

M4（RAG）、M6（多 agent）、M8（provider 抽象）在這門課用不到。學員問起的話，明確告訴他那是另一門課，不要硬扯。
