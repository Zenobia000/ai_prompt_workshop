# 把工作沉澱成資產 — AI 工作流沉澱工作坊

> 一天工作坊。學員帶一個「這個月做過三次以上」的工作進來，
> 帶一個**做好、驗證過、別人也能用**的 skill 資料夾出去。

---

## 這門課在教什麼

不教 prompt 框架。教一件事：

> **把你重複在做的工作，變成一份下次不用重想的資產。**

市面上的 prompt 框架（STRIKE、CTCO、CO-STAR…）都在幫你把**話講好**。
但現在的模型不缺你把話講好，缺的是**你腦袋裡那份它拿不到的東西** —— 你的驗收標準、你的禁區、你踩過的雷。

所以這門課的產出不是「一句更厲害的 prompt」，是**一個資料夾**。

---

## 一句話心法

> **模板沉澱措辭，會過期；skill 沉澱判斷，會增值。**

七條心法的完整版在 [`student_download/00_課前/心法卡.md`](student_download/00_課前/心法卡.md)（一頁，可印出來貼牆）。

## 課程結構

| 單元 | 標題 | 學員帶走什麼 |
|---|---|---|
| **00** | 課前準備 | 一個真實任務 + 工作盤點單 |
| **01** | 只有三個問題，你只需要答第三個 | 瘦身後的 prompt ＋ 雜訊清單 |
| **02** | AI 不是猜不到，是你沒說 | 五類盤點表 |
| **03** | 把工作寫成食譜 | 第一張填空卡 |
| **04** | 從一張卡變成一個資料夾 | **第一個 skill 資料夾** |
| **05** | 怎麼知道它真的有用 | 通過率數字 ＋ 補完的 skill |
| **06** | 不要讓資產爛掉 | 汰換規則 ＋ 個人資產庫索引 |

單元 01–06 是一條線，用**同一個範例**從頭走到尾（會議逐字稿 → 行動項清單），
學員同時用**自己帶來的任務**平行做一份。

## 講師快速上手

1. 先讀 [`docs/課程設計說明.md`](docs/課程設計說明.md) —— 為什麼這樣設計、每段要打中什麼
2. 再讀 [`docs/講師手冊.md`](docs/講師手冊.md) —— 逐段時間表、演練指令、翻車點與救法
3. 開課前把 `student_download/` 整包給學員，並發出**課前作業**（見該資料夾 README）

---

## 學員快速上手

1. 下載整個 [`student_download/`](student_download/) 資料夾
2. 課前填好 `00_課前/課前準備單.md`
3. 課程中講師會指示開哪一個單元

---

## 需要什麼工具

任一個能「讀你上傳的檔案 + 記住你的自訂指令」的 AI 工具都可以。
課程刻意做成**工具無關** —— 你做出來的是一個資料夾，換工具只是換裝法。

裝法對照見 [`student_download/C_收成資產/C4_工具安裝對照.md`](student_download/C_收成資產/C4_工具安裝對照.md)。
