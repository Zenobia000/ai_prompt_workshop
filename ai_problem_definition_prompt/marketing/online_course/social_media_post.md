## 2. 反常識型 ★ 轉發率最高

**視覺：** 純文字卡，「80%」做大

```
Claude Code 的創造者，在 Opus 5 上線那天
砍掉了自家 80% 的系統提示。

模型表現反而更好。

他的建議是：
「每六個月，刪掉你的 CLAUDE.md、刪掉你的 skills、刪掉你的 hooks。」

⸻

聽起來像在說「別做了」。
但他同一場訪談的第一守則是：

「給它一個驗證自己成果的方法 —— 品質會變 2 到 3 倍。」
「驗證，大概是大家最沒做對的那一件事。」

⸻

所以真正的訊息是：

會被模型升級淘汰 → 你寫的「怎麼做」
不會被淘汰       → 你沒寫下來的「怎麼算做好」

你存的那堆 Prompt 是前者。所以它們才會過期。

⸻

我把這件事做成了一整章：
刪光你的 skill，一塊一塊加回來，量出哪一塊真的在撐分數。

## 3. 反向篩選型 ★ 線上課專用（降低退款率）

**視覺：** 純文字，紅色警示框

```
這門課我先講不適合誰。

❌ 從沒用過 AI 對話工具的
   → 請先去上基礎操作課，這堂會太跳

❌ 工作內容每次都全新、完全不重複的
   → 沒有東西可以沉澱

❌ 想拿 100 個現成 Prompt 模板走的
   → 這堂課一個模板都不發

❌ 不願意花一週做作業的
   → 第二章結束有一道關卡：
      你要實際用一週、上傳對話紀錄，第三章才解鎖

⸻

為什麼要這樣設計？

因為第三章的原料，就是那一週的對話紀錄。
你跟 AI 說的每一句「不對，再短一點」「把負責人加上去」——
那些就是你的判斷標準當場被逼出來的那一刻。

沒有那一週，你會坐在那裡憑空想「我的驗收標準是什麼」，
然後寫出「要專業」「要完整」這種沒用的東西。

⸻

如果上面四點你都沒中，歡迎。
第一章免費試看。

## 4. 信任訊號型 ★ 線上課專用

**視覺：** 「每季複驗」四字大字

```
一個線上課不太願意承認的事實：

你三月錄的「這個 Prompt 很有效」，
八月模型一改版，可能就不成立了。

⸻

**每季複驗一次，紀錄公開在課程公告欄。**

為什麼要做到這種程度？

因為這門課本身就在教一件事：
你的資產會過期，所以要定期重測、該刪的刪掉。

一門教你定期重測的課，自己當然要定期重測。

## 6. 短影音腳本（15–30 秒，9:16）

### A｜消融實驗 ★ 最有畫面

```
[0-3s]   畫面：一個 skill 資料夾
         字卡：「這是我花兩小時做的」

[3-8s]   刪掉「步驟」那一段 → 跑考卷 → 9/10
         字卡：「刪掉『怎麼做』」

[8-14s]  改成刪掉「驗收檢核」 → 跑考卷 → 4/10
         字卡：「刪掉『怎麼算做好』」

[14-21s] 字卡：「你花時間寫的，模型不需要。
                 你沒花時間寫的，才是在撐分數的那個。」

[21-25s] 課程卡 + 「第一章免費試看」

## 7. Email 序列文案要點

| 信件 | 觸發 | 核心訊息 |
|---|---|---|
| 購課歡迎 | 立即 | 先講關卡的存在，設定期待 |
| 第一章完成 | 完成 Ch1 | 「你現在知道它怎麼壞了」 |
| **關卡啟動** ★ | 完成 Ch2 | 這一週要做什麼、怎麼存紀錄、檢查清單 |
| **關卡提醒 D+3** ★ | 3 天後 | 「做第一次了嗎？」＋ 常見卡點 |
| **關卡提醒 D+7** ★ | 7 天後 | 「兩次就夠了，上傳吧」降低門檻 |
| 第三章解鎖 | 上傳後 | 恭喜 + 這一章要拿到一個數字 |
| 完課 | 完成全部 | 預告 30 天回訪 |
| **30 天回訪** ★★ | 完課 +30 天 | **只問一題：「你那個 skill 還在用嗎？」** |

> 最後一封是本課最重要的一封信 —— 它同時是**成效指標**與**下一輪的社會證明來源**。
> 回覆「還在用」的比例，就是這門課真正的成績單。
