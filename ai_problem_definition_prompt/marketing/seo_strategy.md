# SEO 與內容策略

適用於 `landing_page.md`（實體工作坊）與 `online_course/landing_page.md`（線上課）。

先講一個限制：以下的關鍵字分層是從搜尋結果地景與競品標題結構推斷的，**沒有實際搜尋量數據**。上線前請用 Google Keyword Planner、Ahrefs 或 Semrush 驗證一次，特別是頭部詞的競爭度。

---

## 1. 現況診斷：目前的標題不可用

| 目前 | 問題 |
|---|---|
| 「AI 沉澱戰法：從提問到資產」 | 「沉澱戰法」是自創品牌詞，沒有人搜尋 |
| 「你上個月調出來的那個好用 Prompt，還在嗎？」 | 好鉤子，但零搜尋量 |

品牌詞要等有品牌之後才有用。現階段標題必須讓還不認識你的人搜得到。

解法不是把鉤子丟掉，是換位置：**帶關鍵字的標題放 H1 與 title tag，鉤子降為副標。**

## 2. 競爭地景

| 競品 | 定位 | 對我們的意義 |
|---|---|---|
| Google「AI 職場通識學程」「Prompting Essentials」 | 免費、官方證書、教 5 步驟提示語框架 | **最大的價格壓力**。他們教「建立專屬提示語資料庫供重複使用」 |
| 大人學「用 AI 提升工作效率的實戰工作坊」 | 實體、職場情境（郵件、企劃、逐字稿、試算表） | **場景最接近的競品** |
| 天地人學堂 AI 系列 | 企業培訓量大，工具導向 | 舊課的來源，受眾重疊 |
| 台灣人工智慧學校、李宏毅公開課 | 技術向、免費 | 受眾不同，不直接競爭 |
| Learn Prompting、promptingguide.ai | 免費線上指南 | 佔據「提示工程」資訊型搜尋 |

### 一個對定位很關鍵的發現

Google 官方課程的賣點之一是「建立專屬提示語資料庫，供重複使用」。

這跟我們的「沉澱」表面上重疊，但停在存模板。**我們整堂課的第四章就在證明存模板會過期。**

這是可以正面對打的角度，而且對方是 Google，講起來有份量：

> 大家都叫你建立提示詞資料庫。但沒有人告訴你，模型一升級，你存的那些會失效。
> Claude Code 團隊在 Opus 5 上線時，砍掉了自家 80% 的系統提示。

免費課程教你「存」，我們教你「存什麼、怎麼驗、什麼時候該刪」。這是付費課唯一站得住的理由。

## 3. 關鍵字分層

### 頭部詞（高量、高競爭，靠內容行銷慢慢攻）

`AI 課程`、`AI 課程推薦`、`提示詞教學`、`prompt engineering`、`ChatGPT 教學`

短期排不上。用部落格文章佈局，不要押在課程頁。

### 中段詞（landing page 主攻）

| 關鍵字 | 放哪裡 |
|---|---|
| `AI 提示詞課程` | title tag、H1 |
| `AI 提示詞工作坊` | title tag（實體版）、H1 |
| `AI 提升工作效率 課程` | H2、內文 |
| `提示詞 框架` | H2（框架比較段） |
| `AI 企業內訓` | 企業包班段、meta |

### 長尾詞（轉換率最高，也是我們獨有的）

這一層最重要。它們競爭低、意圖明確，而且**只有我們的課回答得了**：

| 長尾查詢 | 對應頁面段落 |
|---|---|
| `提示詞模板 會過期` | 為什麼你的提示詞模板會過期 |
| `AI 產出不穩定 怎麼辦` | 規格模糊對明確，各跑五次 |
| `模型升級 prompt 失效` | Block D 汰換與消融 |
| `AI 提示詞 資料庫 怎麼建` | Block C 收成資產 |
| `prompt 框架 還有用嗎` | 框架比較表 |
| `STRIKE 提示詞` `CO-STAR 提示詞` | 三問折疊表（品牌詞截流） |
| `AI 會議紀錄 不準` | 9/8/7 實測數據段 |

最後一組是撿現成的：已經有人在搜尋 STRIKE、CO-STAR 這些框架名，我們的頁面正好在講它們的極限。

## 4. 標題規範

### Title tag

全形 28–30 字內，主關鍵字放最前面，品牌放最後。

| 頁面 | 建議 |
|---|---|
| 實體工作坊 | `AI 提示詞工作坊｜把工作沉澱成可複用資產｜Sunny Data Science` |
| 線上課 | `AI 提示詞課程線上版｜31 堂教你把 AI 對話沉澱成資產` |

### H1

一頁一個，含主關鍵字，跟 title tag 不要完全相同。

| 頁面 | H1 |
|---|---|
| 實體 | AI 提示詞實戰工作坊：把你的工作沉澱成可複用資產 |
| 線上 | AI 提示詞線上課程：把你的 AI 對話沉澱成可複用資產 |

鉤子降為 H1 底下的副標，不當標題：

> 你上個月調出來的那個好用 Prompt，還在嗎？

### H2 佈局（對應搜尋意圖）

每個 H2 都要對應一個真實查詢，不要用內部術語當標題。

| H2 | 對應查詢意圖 |
|---|---|
| 為什麼你的提示詞模板會過期？ | 提示詞模板 會過期 |
| AI 產出為什麼每次都不一樣？三份實測數據 | AI 產出不穩定 |
| 提示詞框架（STRIKE、CO-STAR、CTCO）還有用嗎？ | prompt 框架比較 |
| AI 提示詞課程怎麼選？這堂跟其他課差在哪 | AI 課程推薦、課程比較 |
| 模型升級後，你的提示詞和 skill 還能用嗎？ | 模型升級 prompt 失效 |
| 這堂 AI 提示詞課適合誰？ | 適合對象 |
| 常見問題 | FAQ rich result |

### Meta description

全形 75–80 字，含主關鍵字加具體數字加行動呼籲。

實體版：
> AI 提示詞工作坊，兩個半天。不教你背框架，教你把重複的工作沉澱成可複用、可驗證的 skill 資產。帶走一個通過率數字，證明它真的有用。限額 16 人。

線上版：
> AI 提示詞線上課程，31 堂。從模型原理、提示詞設計到資產沉澱與汰換測試。教你判斷哪些提示詞會被模型升級淘汰，哪些留得住。第一章免費試看。

## 5. 內文的關鍵字佈局原則

**前 100 字內出現主關鍵字一次。** 現在的開頭是鉤子，要在鉤子後的第一段自然帶入「AI 提示詞課程／工作坊」。

**語意變體優於重複。** 提示詞、prompt、指令、提問，交錯使用比同一個詞塞十次好，對讀者也自然。

**不要為了關鍵字破壞句子。** 關鍵字塞到讀起來卡的程度，既傷 SEO 也傷轉換，而且會被 Humanizer 那套標準抓出來當 AI 味。

**數據要獨立成句。** 「三份產出的待辦數量是 9、8、7」這種句子容易被搜尋引擎與 AI 摘要抓取。

---

## 6. AI 搜尋引用優化

2026 年有相當比例的課程查詢不走 Google，而是直接問 ChatGPT、Perplexity、Gemini「推薦 AI 提示詞課程」。要被引用，需要的東西跟傳統 SEO 不完全一樣。

**明確的事實陳述句。** LLM 摘要時抓的是可驗證的斷言，不是形容詞。「限額 16 人」「31 堂約 5.2 小時」「兩個半天中間隔一週」這類句子要獨立、完整、不要藏在表格裡。

**可引用的數據。** 我們有兩組別人沒有的：三份實測產出的 9/8/7 待辦落差、Claude Code 團隊在 Opus 5 砍掉 80% 系統提示。這兩組要在頁面上以完整句子出現，附來源連結。

**結構化的 FAQ。** 問句用真實查詢的措辭，答案第一句就給結論。

**明確寫出「不適合誰」。** LLM 在做推薦時會找篩選條件，寫清楚反而更容易被正確推薦給對的人。

## 7. 技術項目

| 項目 | 規格 |
|---|---|
| URL slug | 實體 `/ai-prompt-workshop`；線上 `/ai-prompt-course` |
| Schema | `Course` 加 `FAQPage`；實體版另加 `Event` |
| OG title / description | 可與 title tag 不同，社群分享用鉤子那句效果較好 |
| 圖片 alt | 含關鍵字，例如「AI 提示詞工作坊 三份實測產出對照 9/8/7」 |
| 內部連結 | 部落格文章互連到課程頁，錨點文字用中段關鍵字 |
| 頁面速度 | 課程預覽影片延遲載入，不要影響 LCP |

## 8. 內容行銷佈局（攻頭部詞用）

課程頁攻不到頭部詞，靠文章。以下每篇都對應一個查詢，並內連到課程頁：

| 文章題目 | 主攻關鍵字 |
|---|---|
| 提示詞教學 2026：ChatGPT、Claude、Gemini 都適用的寫法 | 提示詞教學 |
| 為什麼你存的提示詞模板會過期？Claude Code 團隊砍掉 80% 系統提示的啟示 | 提示詞模板、prompt 失效 |
| STRIKE、CO-STAR、CTCO 三個提示詞框架比較，以及它們共同的盲點 | 提示詞框架比較 |
| AI 會議紀錄不準？三份實測產出告訴你問題在哪 | AI 會議紀錄 |
| AI 課程推薦 2026：免費與付費怎麼選 | AI 課程推薦 |

第二篇和第三篇是我們的主場，別人寫不出來。第五篇要誠實比較，包含推薦 Google 免費課程給不適合我們的人——這對可信度與 AI 引用都有幫助。
