# 線上課程製作藍圖：AI 提示詞戰法 — STRIKE 六字訣 × 辦公室生產力實戰

**總體設計原則：**
* **微課時 (Micro-learning):** 每個影片課時控制在 5-15 分鐘，專注講透一個核心知識點。
* **混合形式 (Mixed-format):** 交錯使用講師畫面、簡報、螢幕錄製、對比 Demo 等形式，維持學習新鮮感。
* **實踐導向 (Action-oriented):** 每個單元結束後都伴隨明確的實作練習，引導學員建立個人提示詞武器庫。
* **零基礎友善 (Beginner-first):** 不假設任何技術背景，會打字就能上手。所有操作以螢幕錄製 + 逐步引導呈現。

### 錄製環境

- 安靜空間（無回音、無背景噪音）
- 乾淨背景（書架/植物/淺色牆面/綠幕）
- 螢幕解析度設定為 1920x1080
- 瀏覽器字體適度放大（確保 AI 工具介面在螢幕錄製中可讀）
- 瀏覽器縮放 125-150%（確保 ChatGPT / Claude 介面清晰）
- 建議準備雙螢幕：一個錄製操作畫面，一個放腳本/備忘

### 本課程特殊注意事項

- **對比 Demo 錄製**：需事先準備好「爛 Prompt」與「STRIKE Prompt」的完整對比腳本，確保錄製時 AI 產出品質差異明顯
- **多工具切換**：課程涉及 ChatGPT、Claude、Perplexity、NotebookLM、Gamma、Napkin AI 等多個工具，錄製前需確保所有帳號登入、介面一致
- **數據實作畫面**：第三章需錄製 Excel + AI 工具的分割畫面操作，建議使用畫中畫或分割螢幕模式
- **模板展示**：展示 Prompt 模板時，建議使用大字體的文字編輯器（如 VS Code / Notion），避免用小字體的對話介面
