# 線上課程製作藍圖：AI 提示詞線上課程

主文件：[`ai_knowledge_sedimentation_workshop.md`](ai_knowledge_sedimentation_workshop.md)。本檔是該課程的線上課版本製作藍圖。

## 總體設計原則

每支影片控制在 5–15 分鐘，一支講透一個點。

本課大量概念靠對比實驗建立體感，影片以螢幕錄製實測為主體，不用簡報講道理。

第二章與第三章之間設一道強制作業關卡。學員必須實際使用一週並留下對話紀錄才進得去。這是課程結構的一部分，不是選配。

不假設技術背景。產出是純文字資料夾，全程複製貼上。

最後一項最容易被忽略：本課的教學內容會隨模型能力變動，每支影片要標保鮮等級，決定改版時重錄哪些。細節見 Part G。

## 本課線上化的兩個特殊挑戰

### 一、實體課的「隔一週」怎麼搬到線上

實體版是兩個半天中間隔一週，讓學員實際使用後再回來收成。

線上版反而更好處理，不需要喬時間，改成章節解鎖關卡：

```
第二章結束 → 作業關卡：上傳 2–3 份對話紀錄 → 第三章解鎖
```

平台若不支援強制解鎖，改成強烈提示加進度提醒信。但不要拿掉這道關卡，第三章沒有原料就做不了。

### 二、錄製的 Demo 會過期

本課教「不要押注在模型會出錯」，但影片一旦錄下就是當期模型的行為。

解法是錄分歧，不要錄錯誤。

| 不要錄 | 要錄 |
|---|---|
| 「你看，AI 答錯了」 | 「三份都對，但三份不一樣」 |
| 單次好壞對比 | 同一輸入跑多次的變異 |
| 特定模型的失敗案例 | 降低條件（低 effort、抽掉資料）製造的可控崩壞 |

前者半年就假，後者是結構性事實，模型再強也成立。

## 課程時數估算

| 區塊 | 課時數 | 總時長 |
| :--- | :--- | :--- |
| 第零章：開場 | 2 堂 | 16 分鐘 |
| 第一章：認識這台機器 | 6 堂 | 60 分鐘 |
| 第二章：提示詞作為設計 | 6 堂 | 63 分鐘 |
| 作業關卡 | 1 堂 | 5 分鐘 |
| 第三章：收成資產 | 7 堂 | 81 分鐘 |
| 第四章：汰換與消融 | 6 堂 | 59 分鐘 |
| 附錄 | 3 堂 | 27 分鐘 |
| 合計 | 31 堂 | 約 311 分鐘（5.2 小時） |

比實體版的 8 小時短，因為線上版拿掉了現場實作的等待時間，實作改為學員自行完成。但作業關卡那一週不能省，它在課程時長之外，卻屬於課程結構。

## Part F — 錄製設備與環境

設備與環境需求同一般線上課，此處只列本課特殊項。

多次取樣的錄製：實驗一（同題問三次）、2.2（跑五次）、2.3（各跑五次）需連續錄製多輪，建議一鏡到底不剪，剪掉會失去說服力。

三分割畫面：1.4（三家工具同一題）需三個視窗並排，建議 4K 錄製後裁切。

對話紀錄的呈現：2.4 對話迭代是本課核心，錄製時要讓每一句修正在畫面上停留足夠久，並用標註工具圈出來。

消融實驗：4.3 需要四種條件各跑一次，建議先跑完存檔再錄講解，避免影片過長。

每支實驗影片片尾加註實測日期與模型版本，讓學員知道這支的時效。

## Part G — 影片保鮮期管理

本課教「模型會變強，所以要定期重測」。課程自己也適用這條規則。

### 保鮮等級與處理

| 等級 | 定義 | 影片數 | 處理方式 |
| :--- | :--- | :--- | :--- |
| 結構 | 模型再強也成立（三問、五類、驗收方法、交棒） | 約 18 支 | 不用重錄 |
| 需驗 | 結論應該仍成立，但要重跑實驗確認 | 約 8 支 | 每個模型世代重跑，結論變了才重錄 |
| 會過期 | 工具介面、平台名單、價格 | 約 5 支 | 每 3–6 個月重錄 |

### 檢查流程（每個主要模型世代或每季）

1. 重跑所有「需驗」級影片的實驗
2. 結論仍成立就在課程公告欄註明「已於某年某月複驗」；結論改變就重錄該支，舊版下架
3. 重錄所有「會過期」級影片
4. 更新工具與價格附件

### 為什麼要公開這件事

把保鮮機制寫進課程頁面，本身就是差異化。

「這門課每季複驗一次實驗數據，複驗紀錄公開在課程公告欄。」

市面上沒有 AI 課程做這件事，而且它跟課程主張完全一致。一門教你定期重測資產的課，自己當然要定期重測。

反過來說，如果你不做，第一個發現影片過期的學員就會在評論區指出來，那個傷害遠大於重錄的成本。
