# C3　填空卡

`C1` 撿回了判準，`C2` 補齊了缺口。這一份把它們排成一張卡，然後變成資料夾。

---

## 一份工作沉澱下來，動作只有三個

```
    每次都一樣的部分   →  寫死          （步驟）
    每次都在換的部分   →  挖空          （食材）
    做完長什麼樣       →  附上去        （成品照）
```

大部分人只做前兩個，然後很奇怪為什麼每次拿到的東西都不太一樣。

**沒有成品照的食譜，做十次有十種樣子。**

---

## 只挖你真的看過它變過的

| 第幾次做 | 你在幹嘛 |
|---|---|
| 第一次 | 在做事。還不知道哪些會變 |
| 第二次 | 在確認不是偶然 |
| **第三次** | **這時候你才看得出哪些是真的不變** |

你這一週做了 2–3 次，剛好到位。

翻開你的對話紀錄，比對每一次：**哪些地方你每次都貼不一樣的東西？** 那些才是要挖空的。

沒看過它變的，先寫死。太早挖空，會把「這次剛好這樣」寫成「永遠這樣」。

```
比對三次紀錄，我發現每次都在換的是：

・_____________________________________________

・_____________________________________________
```

## 現在變成資料夾

填空卡已經能用了，但它還缺三樣：沒有可以逐條打勾的檢核表、沒有範例、沒有證據。

### 動手

1. 把 `空白skill模板/` **複製一份**，改成你的任務名稱
2. 把填空卡的內容填進 `SKILL.md`
3. 把 `C1` Step 4 的驗收標準填進 `驗收檢核.md`
4. 把禁區填進 `禁區.md`
5. 把你認可的成品丟進 `好範例/`
6. 把這一週不滿意的產出丟進 `壞範例/`，並加註「錯在哪」

```
你的任務名稱/
├── SKILL.md          ← 填空卡的內容
├── 驗收檢核.md        ← C1 Step 4
├── 禁區.md            ← C1 Step 4 ＋ C2 的 ④
├── 好範例/            ← C2 的 ⑤
├── 壞範例/            ← 這一週不滿意的產出
└── 考卷.md            ← 下一步 C5 建
```

卡住的話翻 `../公版任務/範例skill_會議紀錄轉行動項/`，那是做好的完整範例。

### 裝進工具

裝法見 `C4_工具安裝對照.md`。裝不起來不影響，保底做法是整包貼進對話。

**不要花超過 20 分鐘在裝工具上。** 你的資產是那個資料夾，不是那個工具。
