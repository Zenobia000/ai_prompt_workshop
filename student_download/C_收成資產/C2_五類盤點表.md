# C2　五類盤點表 — 補齊沒抽到的

`C1` 你從對話紀錄裡撿回了一批判準。但對話紀錄只涵蓋你**這一週實際遇到**的狀況。

這張表用來補齊剩下的。

---

## 值得寫下來的，只有這五類

| # | 類型 | 白話 | 為什麼模型拿不到 |
|---|---|---|---|
| ① | **驗收標準** | 怎樣算可以交出去 | 這是你的品味，不是常識 |
| ② | **私有事實** | 術語、規則、禁區、人名、代號 | 不在它的訓練資料裡 |
| ③ | **流程順序** | 先做什麼、中間停在哪給誰看 | 你的組織才有 |
| ④ | **負例** | 不要變成這樣 | 資訊量比正例高 |
| ⑤ | **參考成品** | 一份你認可的 | 比一百句描述都準 |

這張表裡**沒有「說話技巧」那一格**。那就是「不被框架綁住」的具體意思：值得寫的東西裡，一句話術都沒有。

## 補齊：一類一類問自己

### ① 驗收標準

C1 已經抽到不少。這裡只補一個角度：

> **有沒有哪種狀況，是這一週剛好沒遇到、但每個月會遇到一兩次的？**

例如月底的版本、跨部門的版本、給外部客戶的版本。

```
・_____________________________________________

・_____________________________________________
```

### ② 私有事實

提示：新人來做這件事，會問你哪些問題？

```
・術語 / 代號：_________________________________

・我們公司的慣例：______________________________

・不能碰的：___________________________________
```

### ③ 流程順序（多數人這格是空的，要特別想）

如果你要口頭教一個新人做這件事，你會怎麼分步驟？

```
Step 1  ________________________________________

Step 2  ________________________________________

Step 3  ________________________________________
```

**有沒有哪一步做完要先停下來給誰看？**

```
_______________________________________________
```

> 這一條你自己做的時候是自動的，所以想不到。但別人照做的時候會卡在這裡。

### ④ 負例

C1 抽到的通常是「不要用某個詞」這種細節。這裡補大的：

> **你最不希望這份東西變成什麼樣子？**

```
・不要變成 ____________________________________

・不要變成 ____________________________________
```

### ⑤ 參考成品（最多人跳過，價值最高）

```
我要用的那一份是：______________________________

它好在哪（寫一句）：____________________________
```

**還有一份做壞的嗎？**

```
我要用的壞範例是：______________________________

它爛在哪：______________________________________
```

沒帶的話，這一週你跑出來不滿意的那些就是現成的。直接存進去。

## 檢查

回頭看五格。如果哪一格還是空的：

| 空的那格 | 代表什麼 | 怎麼辦 |
|---|---|---|
| ① 驗收標準 | 最嚴重。你每次交件都在憑感覺 | 回 C1 用三個引出技法再挖一次 |
| ② 私有事實 | 可能真的沒有，也可能你太習慣沒發現 | 問自己：新人會問什麼 |
| ③ 流程順序 | 這個任務可能真的是單步的 | 單步任務不需要流程，跳過沒關係 |
| ④ 負例 | 你還沒踩過雷，或忘了 | 課後補。踩到就回來寫 |
| ⑤ 參考成品 | 手邊沒帶 | 課後補上，這格很值錢 |

> ①③④ 這三格全部都在答第三問：怎麼算做好了。
>
