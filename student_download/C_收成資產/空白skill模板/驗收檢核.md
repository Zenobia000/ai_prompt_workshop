# 驗收檢核 — 【你的任務名稱】

> 交出去之前逐條打勾。**有任何一條沒過，就不能交。**

---

## 唯一的規則

> ### 每一條都要能用**一句 yes/no** 回答。

| ❌ 不可以這樣寫 | ✅ 要改成 |
|---|---|
| 要夠專業 | 沒有出現口語詞（「蠻」「其實」「應該啦」） |
| 要夠詳細 | 每個項目都有負責人和日期 |
| 排版要清楚 | 一頁以內，用表格不用長段落 |
| 語氣要恰當 | 沒有出現驚嘆號 |
| 要抓到重點 | 開頭三行內出現結論 |

判斷方法：**把這條唸給一個沒做過這件事的人聽，他能不能直接回答「有」或「沒有」？**
不能 → 還沒寫完。
