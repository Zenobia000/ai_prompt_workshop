## Step 1　把每一句修正畫出來

逐份打開對話紀錄，把**你說的每一句「不對，改成……」**畫線標出來。

包含這些形態：

```
「太長了」「再短一點」「壓到一頁」
「把 XX 加上去」「少了 XX」
「不要用 XX 這種說法」
「參考我上次那份」
「這個是 A 不是 B」
「這裡怪怪的，重寫」
```

最後一種特別重要。**「怪怪的」代表你認得出但說不出**——那正是這堂課要處理的東西。等一下要逼自己把它講清楚。

## Step 3　把「怪怪的」逼出來

回頭看你標成「這裡怪怪的」的那幾條。它們現在還不能用。

### 三個引出技法

**技法一：對比引出**

把你嫌棄的那一版，跟你認可的那一版並排，問自己：

> 這兩份差在哪？我為什麼收這一份、不收那一份？

人在**比較**的時候說得出判準，單看一份的時候說不出。這是引出隱性知識最可靠的方法。

```
我嫌棄的那份，問題是：____________________________

所以規則是：____________________________________
```

**技法二：退件倒推**

想一次你被退回、或自己重做的經驗。

> 那次是哪裡不對？我當時是**看到什麼**，才知道它不對？

那個「看到什麼」，就是你的檢查點。

```
那次的問題是：__________________________________

所以規則是：____________________________________
```

**技法三：分歧倒推**

如果你這一週跑過同一件事兩次以上，把兩次的產出比一比。

> 哪些地方它兩次處理方式不一樣？

每一個不一樣的地方，都是一個你沒有拍板的判斷點。

```
兩次不一樣的地方：______________________________

我們公司的答案是：______________________________
```
