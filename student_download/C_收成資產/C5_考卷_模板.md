# C5　考卷 — 拿到你的第一個數字

沒有這一節，你今天做的就只是一個「感覺不錯」的資料夾。

---

## 為什麼不能靠感覺

新做的東西，你會覺得它好用——因為你剛做完，你記得每一個細節。

一個月後你不記得了，那時候才是真的考驗。所以今天要留下一個**數字**。

```
不用 skill    ___/5
用了 skill    ___/5
```

而且不只是為了證明給別人看。**沒過的那幾題，會直接告訴你 skill 缺什麼。**

---

## 出考卷

### 規則一：用真實案例，不要編

從你這一週實際做過的、以及過去做過的案例裡挑。編出來的題目測不出東西——你會不自覺編出你的 skill 剛好處理得了的那種。

### 規則二：5 題就夠

寧可 5 題真實案例，不要 10 題編出來的。時間有限，5 題跑得完。

### 規則三：一定要放難的

五題全是簡單案例等於沒測。至少放兩題：一題**你上次做壞的**，一題**特殊狀況**（資料不完整、有例外、跟平常不一樣）。

## 怎麼算「過」

不要打 1–10 分。分數不可重現——你今天給 7 分，明天同一份東西給 5 分。

改成二元：

> **這一題的產出，通過 `驗收檢核.md` 的每一條了嗎？**
> 全過就是過。任何一條沒過就是沒過。

沒有中間值，沒有「差不多」。

## 基線不用重跑

你的「沒有 skill」那一輪，昨天已經跑過了。

`B1` 的砍字實驗、`B2` 的模糊版五次、還有這一週前一兩次的產出——那些就是基線，而且比今天現場重跑更誠實（那時候你還不知道自己的驗收標準長什麼樣）。

## 讀你的成績單

```
基線  ____/5   →   沉澱後  ____/5
```

### 分數上升了

先別急著收工。看沒過的那幾題：**它們沒過的，是不是同一條檢核？**

是的話，那不是幾個問題，是**一個**問題。修那一個，一次修掉一整類。

### 分數沒變，甚至下降

**這是最有價值的結果，不是失敗。** 一題一題看：

| 沒過的原因 | 代表什麼 | 怎麼修 |
|---|---|---|
| 檢核條目太模糊，我自己也判不出過沒過 | 沒寫成 yes/no | 回去改成可核對的 |
| 產出漏了某個東西，但檢核裡沒這條 | **檢核漏了一條** | 補上去 |
| 它照做了，但做出來不是我要的 | **成品照沒寫清楚** | 回 `SKILL.md` 補 |
| 每次結果都不一樣 | 你挖的洞太多，或步驟太模糊 | 把不該挖的補回去寫死 |

> 分數沒上升，唯一的意思是：**你的 skill 還沒把腦袋裡的判斷寫完。**
> 而那正是今天要練的事。

## 修完之後

**沒有拿同一份考卷比過，不准說「改好了」。** 換了題目再測，測出來的是新題目簡單，不是你變強。

