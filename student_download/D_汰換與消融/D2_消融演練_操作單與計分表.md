# D2　消融演練 — 操作單與計分表

這一節回答那個你從報名就想問的問題：

> **我今天花的時間，會不會因為模型變強就白費？**

不用猜。量出來。

---

## 這個方法是誰的

Claude Code 的創造者 Boris Cherny，在 Opus 5 上線時砍掉了自家 80% 以上的系統提示，模型表現反而更好。

他的做法是：

> 刪掉整個 system prompt，再一行一行加回來，看每一行實際有什麼影響。

加回來的判準只有一條：**只有當你看到它重複在同一個地方跌倒，才加回那一行。**

我們今天在你自己的 skill 上做一次同樣的事。

---

## 先把你的 skill 拆成三塊

打開你在 Block C 做好的資料夾，把內容歸到三塊：

| 塊 | 包含什麼 | 它在回答 |
|---|---|---|
| **指示塊** | SKILL.md 裡的「步驟」 | 怎麼做 |
| **驗證塊** | 驗收檢核、禁區、成品照 | 怎麼算做好 |
| **範例塊** | 好範例、壞範例 | 長什麼樣 |

```
我的指示塊有 ____ 條
我的驗證塊有 ____ 條
我的範例塊有 ____ 份
```

---

## 分組

全班分四組，每組跑同一份 5 題考卷，但條件不同。

| 組 | 條件 | 我在哪一組 |
|---|---|---|
| 對照 | 三塊都在 | ☐ |
| A | **拿掉指示塊**，其餘保留 | ☐ |
| B | **拿掉驗證塊**，其餘保留 | ☐ |
| C | **拿掉範例塊**，其餘保留 | ☐ |

用同一份考卷。用不同的考卷，比出來的是題目難度，不是 skill 的貢獻。

---

## 計分表

判準跟 Block C 一樣：**通過驗收檢核的每一條才算過，任何一條沒過就是沒過。** 沒有中間值。

> 注意：B 組拿掉了驗證塊，但**評分還是用完整的那份檢核表**。
> 我們要測的是「沒有驗證塊的時候它做得怎樣」，不是「改用寬鬆的標準」。

| 題號 | 通過？ | 沒過的是哪一條 |
|---|---|---|
| 1 | ☐ 過　☐ 沒過 | |
| 2 | ☐ 過　☐ 沒過 | |
| 3 | ☐ 過　☐ 沒過 | |
| 4 | ☐ 過　☐ 沒過 | |
| 5 | ☐ 過　☐ 沒過 | |

**本組通過率： _____ / 5**

---

## 全班匯總

| 組 | 條件 | 通過率 | 跟對照組差多少 |
|---|---|---|---|
| 對照 | 三塊都在 | ___ / 5 | — |
| A | 拿掉指示塊 | ___ / 5 | |
| B | 拿掉驗證塊 | ___ / 5 | |
| C | 拿掉範例塊 | ___ / 5 | |

---

## 讀結果

### 如果 A 組（拿掉指示）幾乎沒掉

那表示你寫的那些步驟，模型本來就會。它們是你當初不放心才加的。

**可以刪。** 刪掉之後 skill 更短、更好維護、更便宜。

### 如果 B 組（拿掉驗證）掉最多

那表示撐住品質的是你的驗收標準，不是你的步驟說明。

這也是全課的結論：**你花時間寫的「怎麼做」，模型不需要；你沒花時間寫的「怎麼算做好」，才是真的在撐分數的東西。**

而且這個結論不是老師講的，是你自己量出來的。

### 如果 C 組（拿掉範例）掉不少

範例的資訊密度比你想像的高。特別是壞範例——它擋掉的是那種「看起來對、你會直接交出去」的產出。

### 如果結果跟上面都不一樣

**那更好，那是你自己的真實數據。**

這一節真正要教的不是「驗證比指示重要」這個結論，是**「去測，不要猜」這個習慣**。你的任務有你的特性，量出來什麼就是什麼。

把你的結果寫下來：

```
我這個任務，最不能拿掉的是 __________ 塊

因為 _______________________________________________
```

## 現在動手刪

回到你的 skill，把消融證明「拿掉也不會掉分」的東西刪掉。

| 我刪掉了 | 屬於哪一塊 | 刪掉後通過率 |
|---|---|---|
| | | ___ / 5 |
| | | |

刪完再跑一次同一份考卷，確認分數沒掉。

**這是今天最反直覺的一個動作。** 大部分人做完 skill 只想往上加，不會想刪。但一份會長大又不會瘦身的資料夾，一年後你就不敢動它了，然後你就不用它了。

---

## 什麼時候要再跑一次

Boris 講每六個月。但模型改版比這快，而且日曆到期沒有人會記得。

改成**事件觸發**：

```
以下任一件事發生 → 跑一次消融

☐ 換了模型，或工具宣布模型升級
☐ 工具改版，介面或功能有變
☐ 連續兩次覺得產出怪怪的
☐ 有人跟你說「這個 AI 現在很強，你那套是不是可以簡化」
```

把這四行抄進你的 `SKILL.md` 最後面。它會提醒未來的你。

---

## 這一節的收束

早上第一天我說，所有提示詞框架都在問三個問題，第三個沒有人幫你答。

你這兩週做的整個資料夾——成品照、驗收檢核、禁區、壞範例——**全部都在答第三個問題。**

而剛剛的消融實驗，是你自己量出來的證據：那一格確實是撐住品質的地方。

所以下次有人跟你介紹一個新框架、新工具、新方法，你只要問一句：

> **它幫我答第三問了嗎？**
