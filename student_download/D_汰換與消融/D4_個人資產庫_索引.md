### 怎麼排優先序

不是挑最難的，也不是挑最重要的。挑**這兩個乘起來最大**的：

```
       做的次數        ×        每次多花的時間
   （越常做越值得）          （越煩越值得）
```

> 一個月做一次的年度報告，再痛也不急。
> 一天做三次的小事，再小也該先沉澱。

## 什麼時候要回來重跑考卷

任一情況發生，就把 `考卷.md` 拿出來跑一次：

- [ ] 我改了 skill 的任何一條規則
- [ ] 換了 AI 工具，或工具改版 / 換模型
- [ ] 例行半年檢查
- [ ] **連續兩次覺得「產出怪怪的」** ← 這個訊號很多人忽略

## 半年檢查清單（五分鐘）

- [ ] 拿同一份考卷跑一次，分數有沒有掉
- [ ] 把「怕 AI 出錯」的規則暫時刪掉再跑一次 → 分數沒掉就永久刪
- [ ] 這半年新踩的雷，有沒有補進 `禁區.md`
- [ ] 有沒有哪一條規則，我答不出它從哪來 → 刪
- [ ] 好範例還是我認可的嗎（品味會變）

## 一年後你可能會發現的事

有些 skill 會**變得不需要**。

模型變強，某些你當初辛苦寫的東西它自己就會了。
這種時候的正確反應是**開心地刪掉**，不是捨不得。

> **會被刪掉的，是「怕 AI 出錯」的那些。
> 不會被刪掉的，是「你覺得怎樣算做好了」的那些。**

而後者，就是你今天真正做出來的東西。

## 最後

> 早上說過，所有 prompt 框架都在問三個問題：
>
> ```
> ① 我要什麼   ② 我給你什麼   ③ 怎麼算做好了
> ```
>
> 你今天做的整個資料夾 —— 成品照、驗收檢核、禁區、壞範例 ——
> **全部都在答第三個問題。**
>
> 所以下次有人跟你介紹一個新框架，你只要問一句：
>
> ### 它幫我答第三問了嗎？
