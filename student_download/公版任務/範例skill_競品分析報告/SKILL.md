# SKILL：市場競品動態報告（決策會議用）

## 什麼時候用我

- 每季（或每月）決策會議前，或客戶／老闆突然問「這個市場最近怎麼樣」
- **不要用在**：進入市場的深度評估或投資金額試算（那是深潛型分析，另一個任務）、業務打單的 battlecard

## 你要先給我的東西（每次會換的）

1. 〔本期查證到的來源〕：政府統計頁、月度銷售戰報、財報段落、官網價格頁、徵才頁——用工具的搜尋當場查，或把頁面／PDF 直接貼進來
2. 〔上一期的報告〕：讓我知道哪些是舊聞、哪些數字該更新
3. 〔這次要回答的決策問題（KIT）〕：本期客戶最關心的 2–3 個問題

## 步驟（不變的）

1. 逐條標註來源：類型（政府統計／財報／媒體／新聞稿／社群／徵才）、日期、可信度（高／中／低）
2. 模型知識截止日之後的市況，**必須開搜尋查證或由我提供資料**；查不到就寫「未查得」，不准補
3. 無來源的最高級宣稱（第一、最大、突破 X 萬）一律降級為「對方宣稱」
4. 同一件事有兩個口徑（電動車內市佔 vs 整體市場占比、累計 vs 活躍、促銷價 vs 常態價），**並列呈現**並標明口徑
5. 挑出對本期決策問題影響最大的**三條**動態，其餘一行帶過
6. 每條動態三段式：【事實】（來源＋日期）→【影響】（對照客戶的決策問題）→【建議】（有負責人與時間點）
7. 交付前先跑一遍《驗收檢核.md》，任何一條不過先修再交

## 成品長什麼樣

一頁。開頭一句執行摘要，主體三條三段式動態，一張關鍵數字對照表（每格帶來源日期），末行是下期要盯的兩個信號。語氣給決策者：直接、有數字、沒有形容詞。

參考 `好範例_當期報告.md`（每期用真實數據重跑）；反面教材見 `壞範例_解剖.md`。
