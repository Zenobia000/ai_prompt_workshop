# 三份真實產出 — 對照（逐字稿 A）

> **這不是編出來的。** 三個人用三個不同的 prompt，實際跑同一份逐字稿 A 的結果
> （2026-08 實測）。
>
> 先比你們自己的產出。比完之後再打開這份對照。

---

## 三個人用的 prompt

| | prompt |
|---|---|
| **A** | 幫我整理這份會議逐字稿 |
| **B** | 幫我把這個會議整理成會議紀錄，給沒參加的同事看 |
| **C** | 總結一下這場會議 |

---

## 先講一件會讓你意外的事

**三份都很不錯。**

三份都自動產出了「負責人 ＋ 期限」的待辦表格，沒有人只丟一段摘要給你。
連最隨便的「總結一下這場會議」都給了七項待辦。

> 如果你以為今天要學的是「怎麼把 prompt 寫好一點讓 AI 認真做」——
> **不是。它已經很認真了。**

問題在別的地方。

---

## ① 三份的待辦事項數量不一樣：9 / 8 / 7

| 行動項 | A | B | C |
|---|---|---|---|
| Android hotfix | 有 | 有 | 有 |
| 指派人力驗 staging | 有 | 有 | 有 |
| 交 user flow | 有 | 有 | 有 |
| 會員系統工程量評估 | 有 | 有 | 有 |
| 交會員系統設計稿 | 有 | 有 | 有 |
| 618 風格指引 | 有 | 有 | 有 |
| 自製 landing page | 有 | 有 | 有 |
| **購物車五月底上線** | 有 | **沒有** | **沒有** |
| **六月初促銷 campaign** | 有 | 有 | **沒有** |
| **合計** | **9** | **8** | **7** |

> ### 「購物車五月底上線」是這場會議最重要的 Q2 交付。
> ### 三份會議紀錄裡，有兩份沒把它列進待辦。

如果你收到的是 B 或 C 那份，**這件事就沒有人在追**。
而那兩份看起來都很完整、很專業，你不會察覺少了東西。

---

## ② 三份都把「還在評估的方案」寫成了「決議」

逐字稿原文，David 說的是：

> 「Alice，你**評估一下**如果六月只做到會員系統的第一階段——比如只有等級顯示、
> 不含兌換功能——工程量**是不是**能壓在 capacity 內。」

這是**請人去評估**，不是拍板。但是：

| | 怎麼寫的 |
|---|---|
| **A** | 「**決議**：…會員等級系統排第二，且先做第一階段」 |
| **B** | 「**決議事項** #2：會員系統 Q2 只做第一階段」 |
| **C** | 「**主要結論** 1：…Q2 只做第一階段」 |

**3/3 都當成已定案。**

更妙的是，同樣這三份，全部又在「待確認事項」裡寫了：

> 「會員系統第一階段的工程量是否能壓在 capacity 內（待 Alice 下週一評估後確認）」

> ### 同一份文件，前面說「決定只做第一階段」，後面說「還不知道第一階段做不做得完」。
> ### 三份都自相矛盾，而且三份的矛盾一模一樣。

---

## ③ 產出的形狀完全不同

| | 分成幾段 |
|---|---|
| **A** | 主題分段（4 段）＋ 待辦表 ＋ 待確認 |
| **B** | 三句話結論 ＋ 決議表 ＋ 待辦表 ＋ **重要時程表** ＋ **風險與待確認**（5 段，最重） |
| **C** | 討論主軸 ＋ 敘述式結論 ＋ 待辦表 ＋ 待確認 |

B 多產出了「重要時程」和「風險與待確認事項」兩整段，A 和 C 都沒有。
C 多了一個 A、B 都沒注意到的觀察：「會員系統第二階段的排程尚未討論」。

**同一份逐字稿，有人給你 4 段，有人給你 5 段，有人給你 3 段。**

---

## 所以問題在哪

不是 AI 不認真。**是它每一次都替你做了一堆決定：**

| 它幫你決定的 | 但這應該是誰的判斷？ |
|---|---|
| 哪些事算「待辦」、哪些只是「講到」 | **你的** |
| 「還在評估的方案」算不算決議 | **你的** |
| 要不要另外開一段「風險」 | **你的** |
| 要不要把「五月底上線」也列成待辦 | **你的** |

> ### 三個人拿到三份不同的東西，因為三個人心裡「整理好的會議紀錄」長得不一樣，
> ### 而**沒有人把那個樣子寫下來**。

這就是第③問（怎麼算做好了）的空缺。
它不是模型的能力問題，是**資訊問題** —— 你的驗收標準在你腦袋裡，它拿不到。

---

## 給講師的備註

- 這三份是實測資料，**全班產出剛好很像的時候直接拿出來用**
- 不要說「你看 AI 出錯了」。要說：**「三份都不錯。但三份不一樣，而且互相矛盾。」**
- 最有殺傷力的是 ①：**問全班「你們有幾個人的產出裡有『購物車五月底上線』？」**
  沒有的人會當場明白為什麼需要驗收標準
