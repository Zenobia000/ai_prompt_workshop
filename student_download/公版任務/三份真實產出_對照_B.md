# 三份真實產出 — 對照

> **這不是編出來的。** 這是三個人拿**同一份逐字稿 B**、用三個不同的天真 prompt
> 實際跑出來的結果（2026-08 實測）。
>
> 你自己的產出跑完之後，拿來跟這三份對。

---

## 三個人用的 prompt

| | prompt |
|---|---|
| **A** | 幫我把這份逐字稿整理成會議紀錄 |
| **B** | 幫我摘要這場會議的重點 |
| **C** | 幫我整理成會議紀錄，要有決議事項和待辦事項 |

---

## 先講結論

**三份都不爛。** 沒有一份出現明顯的錯誤，三份都抓到了「會員系統延到 Q3」這個關鍵變更，
三份都正確寫出 landing page 由外部工作室 Eric 負責。

**但三份不一樣。而且在同一件事上互相矛盾。**

---

## 它們在哪裡分歧

### ① 推播架構技術債 — 這到底算不算「決議」？

| | 放在哪一段 |
|---|---|
| **A** | **決議事項**「推播架構技術債於 Q3 一併評估」 |
| **B** | **待決事項**「Alice 提議 Q3 排入處理」 |
| **C** | **未決事項**「Alice 先提評估，Q3 規劃時一併討論」 |

> A 說已經定案了，B 和 C 說還沒。**這是直接矛盾。**
>
> 回去看逐字稿：David 說「Q3 一起看。你先寫一份簡單的評估給我」。
> 「寫評估」定案了，「排進 Q3」沒有。**三份都沒把這兩件事分開。**

### ② 購物車五月底上線 — 決議還是進度？

| | 放在哪一段 |
|---|---|
| **A** | 行動項「購物車依計畫上線」 |
| **B** | 「已完成 / 進行中」 |
| **C** | **決議事項**「購物車維持五月底上線…暫不提前」 |

> ⚠️ C 出現**自我矛盾**：它在「決議」寫了「暫不提前」，
> 又在「未決事項」寫了「購物車是否提前至五月中上線」。
> 同一份文件，同一件事，兩個相反的狀態。

### ③ User flow 交付結案 — 要不要寫進去？

| | |
|---|---|
| **A** | 放在進度追蹤表 |
| **B** | 放在「已完成」 |
| **C** | 列為**決議事項第 4 條** |

> 一件已經做完的事，算不算「本次會議的決議」？三個人的答案不一樣。

### ④ 日期換算

| | 「本週五」 | 「下週」 | 「下個月月會前」 |
|---|---|---|---|
| **A** | ✅ 本週五（4/17） | ❌ 原樣 | ❌ 原樣 |
| **B** | ❌ 原樣 | ❌ 原樣 | ❌ 原樣 |
| **C** | ✅ 本週五（4/17） | ❌ 原樣 | ❌ 原樣 |

> **三份都沒有全部換算。** 沒有人跟它說過要換算。

### ⑤ 負責人

| | |
|---|---|
| **A** | 全部有具體人名 |
| **B** | 出現「**全體**」← 沒有人名 = 沒有人會做 |
| **C** | 「David 召集」 |

### ⑥ 自己補的東西

**A 和 C 都新增了一個逐字稿裡沒有的行動項**：

```
「Q3 規劃（含設計師增聘、技術債排程）| David | 月底」
```

逐字稿原文只有：「我們月底做 Q3 規劃的時候再一起看」。
沒有人被指派要辦一場 Q3 規劃會，也沒有人說那是 David 的待辦。

> **它不是在騙你。它是在做它以為你要的事：給你一份看起來完整的紀錄。**

### ⑦ 整份的形狀

| | 分成幾段、怎麼分 |
|---|---|
| **A** | 進度追蹤表 → 決議 → 待決 → 行動項（4 段） |
| **B** | 敘事式，從「最重要的變更」開頭（5 段） |
| **C** | 決議（內含未決子表）→ 待辦 → 備註（3 段） |

---

## 這說明什麼

> ### AI 沒有出錯。它每次都幫你做了一個決定 —— 而那個決定本來該是你做的。

「推播技術債算不算決議」「已完成的事要不要列進來」「相對日期要不要換算」——
這些**全部都是判斷題**，而且**你們公司一定有一個固定答案**。

只是沒有人寫下來，所以每一次它都幫你猜一次，**每次猜的還不一樣**。

```
❌ 錯誤的理解：AI 不夠聰明，所以我要把 prompt 寫得更好
✅ 正確的理解：AI 每次都在幫我做決定，我要把決定收回來
```

---

## 現在做：找出你的分歧點

拿你剛剛跑出來的產出，跟上面三份（或跟隔壁的）比。
**找三個「處理方式不一樣」的地方**——不是找誰對誰錯，是找**哪裡需要你拍板**。

| # | 分歧點 | 我們公司的答案是 | 要寫進食譜的哪一格 |
|---|---|---|---|
| 1 | 例：已完成的事要不要列進決議 | 例：不要，另開「進度」段 | 成品照 |
| 2 | | | |
| 3 | | | |

> 填完這張表，你的填空卡就有東西可以寫了。
> **每一個分歧點，都是一格你以前每次都要重想的判斷。**

## 給講師的備註

三個陷阱（決議推翻／外部廠商／無結論）在 2026-08 的主流模型上**大多不會觸發** ——
模型已經處理得相當好。**不要押注在「它會出錯」上**（那正是舊版 A/B 演練垮掉的原因）。

**但分歧 100% 可重現**，而且分歧本身是更好的教材：
它不需要模型變笨，而且模型越強，「三份都對但不一樣」的說服力越強。
