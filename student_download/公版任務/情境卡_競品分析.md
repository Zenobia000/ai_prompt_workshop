# 情境卡：客戶問「這個市場最近怎麼樣？」

> 本情境使用**真實市場與真實數據**：台灣電動機車市場。
> 你分析的是真實公司（Gogoro、光陽 Ionex、三陽、eMOVING……）的**公開**資訊——
> 這正是實務上競爭情報的合法邊界：公開資訊可以用，假冒身分與非公開資料不行（SCIP 倫理守則）。
> 執行工具限定 Claude Desktop 或 Codex Desktop 的內建功能：搜尋、讀檔、Projects／Skills、排程。

---

## 情境

你是一家產業顧問公司的分析師。你的客戶是一個通路集團的投資部門，正在評估要不要投入電動機車的周邊生意（充換電、保修、配件通路）。

**週四下午 3 點，主管在群組丟了一句：**

> 「客戶下週二要聽台灣電動機車市場的最新動態。你整理一下。」

沒有更多說明。沒有格式、沒有範圍、沒有說要多深。

你手上有：

| 東西 | 在哪 |
|---|---|
| 真實資料來源清單 | 《真實資料來源包.md》——政府掛牌統計、上市公司財報、每月銷售戰報、官網價格、徵才頁 |
| 上一期的報告 | 講師提供（每期用當期真實數據產生） |
| 工具 | Claude Desktop 或 Codex Desktop，開著搜尋 |
| 時間 | 半天 |

## 主管沒說、但你該想清楚的事（三問的第③格）

- 客戶是**投資決策者**：每條動態都要落到「這對投資判斷意味著什麼」
- 會議桌上沒人翻第二頁——**一頁**
- 客戶的幕僚會查證你的數字——每個數字帶**來源與日期**，口徑不一要並列
- 這個市場有現成的口徑陷阱：「龍頭市佔近九成」（電動車之內）與「電動車只占 7%」（整體機車之內）**同時為真**——你怎麼寫，決定客戶怎麼理解這個市場

## 為什麼這個任務值得沉澱

政府每月公布掛牌數、媒體每月出戰報——**素材每個月自動更新，客戶每季固定要聽**。同一個任務、換一批數據、重複發生：這正是 skill 的完美標的。

## 資料紀律（本情境的硬規則）

1. 模型的知識有截止日：**問市況必開搜尋，或把統計頁／財報貼進對話**，二者擇一，不然得到的是編造
2. 每個數字直接查到原始出處才准寫；AI 給的數字要求它**先列引用來源再作答**
3. 對真實公司只使用公開資訊；分析歸分析，不虛構它們的內部數據
