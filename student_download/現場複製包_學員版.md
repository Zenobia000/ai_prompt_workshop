# 現場複製包（學員版）

> 使用規則：每個方塊就是一個完整輸入，**整塊複製、貼進 AI 對話框、送出**，不用改字。
> 有自己任務的人：照方塊的句型換成自己的內容。還沒有想法的人：直接用小禾的版本，全程可以跟完。
> 標「課堂演示」的方塊，上課時看老師跑就好，課後可以自己重跑一次。

---

## 0. 公版素材：小禾的週會逐字稿

全課只用這一份素材。下面所有實驗、迭代、考卷都從它出發。

```text
【行銷部跨部門週會 逐字稿】
日期：2026-08-10（一）10:00–10:40
與會：行銷經理 Maggie、業務主管老周、設計師 Vivian、客服組長阿凱、企劃小禾（主持）

小禾：今天三件事：雙十一檔期的準備、實體 DM 印刷、還有客服反映的退貨頁問題。Maggie 先講檔期。

Maggie：雙十一今年提前開跑，活動頁要在檔期前兩週上線。文案是第一個卡點，業務那邊等文案報價格結構。小禾，文案這週五要給老周，這是死線，別的都可以動，這個不行。

老周：對，我拿到文案才能跟通路談版位。另外我建議滿額贈的門檻從 1500 降到 1200，去年 1500 的轉換不好。

Maggie：門檻的事先不要定。阿凱，你們客服有去年滿額贈的客訴數據，你評估一下降到 1200 會不會讓贈品出貨量爆掉，下週三前給我。

阿凱：可以，我下週三前給。另外退貨頁的問題，上個月退貨相關客訴 47 件，八成是找不到退貨入口。我建議入口移到訂單頁第一層。

Vivian：改入口是小事，我這個月底前可以改完。但如果要連整個退貨流程一起改，那要排到下一季。

小禾：先只改入口，流程改版下一季再議。DM 的事，Vivian 你說。

Vivian：DM 設計稿我週四給。但印刷廠那邊我不熟，之前都是外包的印務窗口在對，那個窗口是誰要問總務，我這邊沒有聯絡方式。

Maggie：印刷廠窗口確認這件事我來追。還有，LINE 官方帳號要不要改版，上次說要討論——

小禾：時間不夠了，LINE 改版下次會議再議。我收一下：文案週五給老周、阿凱下週三前給滿額贈評估、Vivian 月底前改退貨入口、週四給 DM 設計稿、印刷窗口 Maggie 追。散會。
```

## Day 1

### 五個實驗

**實驗一：同一題問三次**（課堂演示；課後自己跑一次）

開三個**全新對話**，每個貼同一份輸入：

```text
總結一下這場會議，列出待辦。

（貼上整份逐字稿）
```

比三份的：待辦數量、最重要的事排第幾、同一件事被寫成什麼。

---

**實驗二：不給資料對給資料**（現場跟著做）

第 1 步——從下面挑**一題跟你工作最像的**，整句貼上（新對話、不給任何資料）：

```text
我們公司內部的「差旅費報支規定」是什麼？每個級距的上限是多少？請條列。
```

```text
我們公司的「請假與補休流程」是什麼？要經過哪些人簽核？請條列。
```

```text
我們部門的「對外報價審核流程」是什麼？多少金額以上要主管核准？請條列。
```

```text
我們公司的「供應商付款流程」是什麼？月結幾天？窗口是誰？請條列。
```

```text
我們公司的「社群貼文發布前審核規定」是什麼？哪些內容要法務看過？請條列。
```

```text
我們公司的「客訴升級處理流程」是什麼？什麼情況要通報到主管層級？請條列。
```

```text
我們公司內部系統的「權限申請流程」是什麼？要填哪張表單？請條列。
```

```text
我們公司的「新人到職第一週 checklist」有哪些項目？請條列。
```

第 2 步——開**新對話**，把你手上的真資料換進去再問一次：

```text
以下是我們公司的內部規定原文。根據這份資料回答：（把你剛剛問的那一題再問一次）

規則：先列出你引用的原文段落，再作答。資料裡找不到的，直接說「資料裡沒有提到」，不要推測。

（貼上你的內規原文——手冊截圖轉的文字、公告信、SOP 文件都可以）
```

手上沒有真資料的人：第 2 步改用公版逐字稿問「這次雙十一有哪些準備事項」，效果相同。

---

**實驗三：思考深度是旋鈕**（課堂演示；課後自己跑一次）

同一題，分別用工具的「快速回答」與「深度思考」模式各跑一次：

```text
根據這份逐字稿排一張時程表：把所有相對日期換算成實際日期（開會日是 2026-08-10 週一），
按時間排序，標出哪兩件事有依賴關係（一件不完成另一件就會卡住），並指出全案最大的單點風險是誰。

（貼上整份逐字稿）
```

---

**實驗四：三家工具跑同一題**（課堂演示）

三家工具各貼一次，比長度、語氣、用不用表格、有沒有自作主張加東西：

```text
把這份逐字稿整理成會議紀錄，發給與會的五個人。

（貼上整份逐字稿）
```

---

**算一次帳**（課堂演示）

```text
粗估一下：我剛剛貼給你的逐字稿大約多少 token？你的回答大約多少 token？
如果我每週做一次、每次來回修 5 輪，一個月大概用掉多少？
中文和英文的 token 計算差在哪？
```

### 框架與它的天花板（課堂演示；課後可自己重跑對照）

**規格模糊版**（跑五次）：

```text
幫我把這份逐字稿整理成會議紀錄，要清楚專業。

（貼上整份逐字稿）
```

**規格明確版**（跑五次）：

```text
把這份逐字稿整理成會議紀錄。驗收條件如下，全部符合才算完成：
1. 一頁以內，用表格不用長段落
2. 分三區：已決議事項／待辦事項／評估中事項（還沒定案的放這裡，不准寫成決議）
3. 每項待辦都有負責人和到期日；相對日期一律換算成實際日期（開會日 2026-08-10 週一）
4. 逐字稿裡沒有明確負責人的，標【待確認】，不准猜
5. 「雙十一活動頁文案週五給業務」放待辦第一列
6. 無結論的議題放最後一區「下次再議」

（貼上整份逐字稿）
```

比的是五次對五次的**可用率**，不是單次好壞。

### ✍ 對話式迭代（現場動手，全課最重要的一段）

**起手式**——有自己任務的人，第一句就這樣問，不用寫好 prompt：

```text
幫我＿＿＿＿。

（貼上你的素材）
```

**修正語句庫**——卡住不知道怎麼修的時候，從這裡挑（每輪只修一件事）：

```text
太長了，一頁以內。
用表格，不要長段落。
每一項都要有負責人和日期。
日期換成實際日期，不要「下週三」。
「＿＿」那件事還沒定案，不要寫成決議。
把最重要的「＿＿」放最上面。
語氣太客氣了，這是內部文件，直接講事情。
不要用「賦能」「打造」這種詞。
你自己加的「＿＿」我沒說過，刪掉。
這一版可以了，停。
```

**小禾完整迭代腳本**——還沒有自己任務的人，照順序一輪貼一句：

```text
第 1 句：總結一下這場會議，列出待辦。（貼上整份逐字稿）
第 2 句：太長了。我要發給三個部門的版本，一頁以內，用表格。
第 3 句：每個待辦要有負責人和到期日，日期換成實際日期，開會那天是 2026-08-10 週一。
第 4 句：「滿額贈降到 1200」那件事是請阿凱評估，不是決議。另外開一區「評估中」放它。
第 5 句：把「活動頁文案週五給老周」放待辦第一列，那是死線。
第 6 句：印刷廠窗口那格不要寫 Vivian，逐字稿裡是 Maggie 要去追，寫 Maggie，後面加【窗口待確認】。
```

跑完之後：**匯出或截圖整段對話**。這份紀錄是第二天的原料，關掉就沒了。

## Day 2

### ✍ 撿修正、歸五類（現場動手）

把你這一週對話紀錄裡每一句「不對，要改成…」抄進工作單：

```text
| 我對 AI 說過的修正原句 | 歸哪類 | 說過幾次 |
|---|---|---|
| 例：每個待辦要有負責人和日期 | ①驗收標準 | 3 |
| 例：開會那天是 2026-08-10 | ②私有事實 | 1 |
|  |  |  |
|  |  |  |

五類：①驗收標準（你的品味） ②私有事實（它的訓練資料裡沒有）
③流程順序（你的組織才有） ④負例（絕不能出現的） ⑤參考成品（你認可的範例）

歸不進五類的句子（例：「再試一次」「好像怪怪的」）→ 不值得寫下來，劃掉。
說過兩次以上的句子 → 打星號，優先寫進驗收檢核。
```

### ✍ 驗收檢核＋跑考卷（現場動手）

**結構化 prompt**——把對話紀錄轉成 skill 骨架（課堂看老師示範，回家照貼）：

```text
以下是我和 AI 完成「（任務名稱）」的完整對話紀錄。請幫我把它整理成一份可複用的工作規格，輸出四個檔案的內容：

1. SKILL.md：這個任務什麼時候用（以及什麼時候不要用）、步驟（不變的寫死、每次會換的用〔挖空〕標記）、成品長什麼樣的一句話描述
2. 驗收檢核.md：從我在對話中的每一句修正提煉，每條都必須能用 yes/no 回答
3. 禁區.md：我說過「不要」「刪掉」「不准」的東西
4. 考卷說明：建議我拿哪些歷史案例當測試題

規則：只能用我在對話裡實際說過的標準，不准替我發明新標準。
來源不確定的條目，標【待確認】。

（貼上完整對話紀錄）
```

**yes/no 句型庫**——寫檢核卡住就套這五個句型：

```text
沒有出現＿＿（口語詞／英文縮寫／「賦能」這類詞）
每個＿＿都有＿＿（每項待辦都有負責人和到期日）
不超過＿＿（一頁／10 列／300 字）
一律換算成＿＿（相對日期→實際日期）
＿＿必須放在＿＿（最重要交付放第一列）
```

**改寫對照**：

```text
要夠專業     → 沒有出現口語詞
要夠詳細     → 每個項目都有負責人和日期
排版清楚     → 一頁以內，用表格不用長段落
不要亂寫     → 素材裡沒有的資訊標【待確認】，不准推測
```

**引出技法**——寫不出標準的時候，挑一個貼：

```text
（對比引出）這裡有兩份成品，A 是我認可的，B 是普通的。
請列出 A 和 B 的具體差異，每一條都寫成可以用 yes/no 核對的句子。
（貼上 A）（貼上 B）

（退件倒推）這份成品當時被退回，退回原因是：「＿＿＿＿」。
請把這個退回原因改寫成 2–3 條可以事先核對的 yes/no 檢查項。
（貼上被退的成品）

（分歧倒推）這兩份成品都「對」，但長得不一樣。
請列出它們所有不一致的地方，每一條後面問我一句：「你要哪一種？」
（貼上兩份）
```

**公版驗收檢核**（小禾版成品——自己還沒寫出來的人，先用這份跑考卷）：

```text
【驗收檢核】全部 yes 才能交
1. 一頁以內，用表格？
2. 分成「已決議／待辦／評估中／下次再議」四區？
3. 每項待辦都有負責人和到期日？
4. 所有日期都是實際日期（沒有「下週三」這種寫法）？
5. 還沒定案的事（滿額贈門檻）沒有被寫進決議區？
6. 最重要交付（活動頁文案）在待辦第一列？
7. 沒有負責人的項目標了【待確認】而不是用猜的？

【禁區】出現任何一條直接退件
- 不准出現逐字稿裡沒有的決定
- 不准用「盡快」「近期」當期限
- 不准把「評估」「討論」寫成「決議」
```

**保底裝法**——工具什麼功能都沒有時，每次對話開頭貼這個框架：

```text
接下來這個任務，照以下規格做。做完先自己逐條核對驗收檢核，有任何一條不過就先修再給我。

=== SKILL ===（貼上你的 SKILL.md 內容）
=== 驗收檢核 ===（貼上你的檢核）
=== 禁區 ===（貼上你的禁區）
=== 參考成品 ===（貼上一份好範例）

本次的素材如下：
（貼上這次的素材）
```

**跑考卷**：從這一週的真實案例挑 5 題。基線直接用 Day 1 的產出，不用重跑。每題逐條對檢核，**全過才得 1 分**：

```text
| 題號 | 素材（哪次的案例） | 基線（Day 1 產出）幾條過 | 裝上 skill 後幾條過 | 得分 |
|---|---|---|---|---|
| 1 |  | /7 | /7 |  |
| 2 |  | /7 | /7 |  |
| 3 |  | /7 | /7 |  |
| 4 |  | /7 | /7 |  |
| 5 |  | /7 | /7 |  |
沉澱前：__/5    沉澱後：__/5
```

### 規則的保存期限（課堂遊戲，判準先記住）

```text
一句話判斷法：
如果今天來做這件事的，是一個很資深的人類同事——這句話我還需要跟他講嗎？

需要講  → 業務要求，永久保留
不需要  → 你只是不放心，模型換代就變雜訊，刪
```

### ✍ 分組消融實驗（現場動手）

四組同一份考卷（公版逐字稿＋公版檢核評分）。各組把「保底裝法」的框架**刪掉指定區塊**再跑：

```text
對照組：全部保留（SKILL＋驗收檢核＋禁區＋參考成品）
A 組：刪掉 SKILL 裡的「步驟」段（指示塊），其他保留
B 組：刪掉「驗收檢核＋禁區＋成品描述」（驗證塊），其他保留
C 組：刪掉「參考成品」（範例塊），其他保留
```

每組跑 5 題，用**同一份公版檢核**評分（自己組的產出自己評，隔壁組抽查一題）：

```text
| 組別 | 拿掉什麼 | 5 題得分 | 跟對照組差幾分 |
|---|---|---|---|
| 對照 | 無 |  | — |
| A | 指示塊 |  |  |
| B | 驗證塊 |  |  |
| C | 範例塊 |  |  |
```

### 交棒測試卡（回家做）

```text
把你的 skill 資料夾原封不動給一個沒做過這件事的同事，附這段話：

「照這包規格，把附件素材做成成品。過程中不要問我，
把你卡住、看不懂、需要猜的地方全部記下來，做完一起給我。」

他記下來的每一條，就是你還沒寫下來的判斷。補進檢核或 SKILL，再找下一個人，三輪就收斂。
```
