# 把工作沉澱成資產 — 學員教材包

> **課前請下載整個資料夾到電腦。**
> 今天結束時，這個資料夾裡會多一個你自己做的 skill。

---

## ⚠️ 課前作業（一定要做）

打開 `00_課前準備/工作盤點單.md`，填好帶來。

**沒填的人今天會沒東西可做** —— 課程從第三個單元開始，全部都是在處理你自己的任務。
範例只是拐杖，你自己的任務才是今天要帶走的成品。

只要填一件事：**你這個月做過三次以上的一項工作。**

---

## 今天要做出什麼

不是一句更厲害的 prompt，是**一個資料夾**：

```
你的任務名稱/
├── SKILL.md          ← 什麼時候用我、怎麼做、做完長什麼樣
├── 驗收檢核.md        ← 幾條 yes/no，全過才能交
├── 禁區.md            ← 絕對不能出現的東西
├── 好範例/            ← 你認可的成品
└── 壞範例/            ← 踩過的雷 ＋ 為什麼爛
```

而且離開之前，你會有一個**數字**證明它有用（不是「感覺比較順」）。

---
