# AI 提示詞實戰工作坊 — 學員教材包

課前請下載整個資料夾到電腦。兩天結束時，這裡會多一個你自己做的 skill。

---

## 這兩天要做出什麼

不是一句更厲害的 prompt，是一個資料夾：

```
你的任務名稱/
├── SKILL.md          什麼時候用我、步驟、成品照
├── 驗收檢核.md        幾條 yes/no，全過才能交
├── 禁區.md            絕對不能出現的東西
├── 好範例/            你認可的成品
├── 壞範例/            踩過的雷，加上為什麼爛
└── 考卷.md            5–10 題真實案例
```

而且離開之前，你會有一個**數字**證明它有用，還有一份**消融數據**告訴你哪一塊真的在撐分數。

---

## 課程形式：兩個半天，中間隔一週

```
Day 1  懂機器、會對話        →  帶走一份對話紀錄
   ↓
中間一週  回去實際用 2–3 次   →  存下每一次的對話紀錄
   ↓
Day 2  收成資產、汰換測試     →  帶走 skill、通過率、消融數據
```

**中間那一週不是休息，是課程的一部分。** Day 2 的原料就是那一週的對話紀錄。

## 課前只要做兩件事

1. 打開 [`00_課前/課前準備單.md`](00_課前/課前準備單.md) 填一填
2. 確認你有一個 AI 對話工具帳號（免費版就可以）

**Day 1 不需要你帶任何素材。** 真正要準備東西的是 Day 1 結束後那一週。

## 隨時可以翻的三份

- [`公版任務/範例skill_會議紀錄轉行動項/`](公版任務/範例skill_會議紀錄轉行動項/) — 做好的完整範例，卡住就翻它

## 需要什麼工具

任何能「上傳檔案」加「記住自訂指令」的 AI 工具都可以。

你做出來的是一個純文字資料夾，換工具只是換裝法，裝法對照見 [`C_收成資產/C4_工具安裝對照.md`](C_收成資產/C4_工具安裝對照.md)。

工具裝不起來也不影響上課，保底做法是把資料夾內容整包貼進對話。**重點是資料夾裡寫什麼，不是它裝在哪。**
