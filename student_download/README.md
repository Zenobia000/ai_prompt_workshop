# 學員包

> 這個資料夾的內容**全部可以直接提供給學員**（上傳到課程平台、課前寄送皆可）。
> 講師限定的教材一律放在 [`../docs/`](../docs/)，不要混進來。

## 使用順序

| 順序 | 檔案 | 什麼時候用 |
|---|---|---|
| 1 | [`講義/`](講義/) 四部 | **課前讀**。理論打底：每章「白話機制 → 失敗對正確案例 → 溝通原則」，讀完你會發現溝通方式是自己推得出來的 |
| 2 | [`公版任務/`](公版任務/) | **課堂主線情境**。「客戶問：這個市場最近怎麼樣？」——**真實市場（台灣電動機車）、真實公開數據**的競品分析：情境卡、實務指導書（附視覺化網頁版）、真實資料來源包、完整範例 skill 與五題考卷。工具限定 Claude Desktop／Codex Desktop 內建功能 |
| 3 | [`現場複製包_學員版.md`](現場複製包_學員版.md) | **課堂用**。每個方塊整段複製貼進 AI 對話框就能跟課 |

### 講義四部

| 部 | 章 | 回答的問題 |
|---|---|---|
| [第一部 它怎麼說話](講義/01_它怎麼說話.md) | 1–3 | 為什麼每次答案不一樣、為什麼聊久會忘、它眼中的世界長怎樣 |
| [第二部 它知道什麼](講義/02_它知道什麼.md) | 4–5 | 幻覺從哪來、什麼必須自己查證、它替你做了哪些決定 |
| [第三部 它怎麼被你影響](講義/03_它怎麼被你影響.md) | 6–8 | 思考深度怎麼調、指令為什麼被忽略、為什麼不能問它「好不好」 |
| [第四部 所以怎麼溝通](講義/04_所以怎麼溝通.md) | 9–10 | 三問怎麼從前八章長出來、模型換代後什麼留得住 |

只能記住一句的話：**第 4 章「形與實」——AI 適合生形（結構、草稿、風格），不適合供實（數據、日期、人名、引言、法條）。事實一律自己查證。**

## 給學員的三句話

1. 課前準備：筆電、網路、至少一個 AI 對話工具帳號（免費版即可），想好一件你這個月做過三次以上的工作，然後把講義四部讀完（約 40 分鐘）。
2. 上課時打開「現場複製包」，跟著老師的進度，貼對應的方塊。
3. 兩天中間那一週的作業在複製包的「本週作業卡」——那一週是課程的一部分，不是休息。

（練習題本規劃中，之後會加入這個資料夾。）
