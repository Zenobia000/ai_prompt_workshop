# A1　五個實驗 — 操作單

這一段沒有投影片。五個實驗，你自己動手跑，跑完填 `A2_模型體感表.md`。

先講清楚為什麼要花 100 分鐘做這件事。

後面三個區塊都在教你「怎麼把判斷寫下來給 AI」。但如果你不知道這台機器會在哪裡壞、一次要花多少錢、為什麼同一句話問兩次結果不一樣，那些判斷你會寫錯地方。

**你不知道它怎麼壞的，就永遠只能當乘客。**

---

## 準備

挑一個**你工作上真的會問的問題**。不用複雜，但要是真的。

例如：「幫我把這段客訴整理成回覆草稿」「幫我從這份數據看出三個重點」「幫我寫一封延期通知」。

```
我要用的問題：

  ________________________________________________
```

五個實驗全部用這一題。用同一題，你才比得出差異。

## 實驗一　同一題問三次

**要看到什麼**：同樣的輸入，不同的輸出。

### 做法

開三個新對話（不是同一個對話問三次，那會被前文影響），各貼一次你的問題。

### 記錄

| | 產出的重點差異 |
|---|---|
| 第 1 次 | |
| 第 2 次 | |
| 第 3 次 | |

**三次一樣嗎？** 完全一樣　／　大同小異　／　差很多

### 這說明什麼

模型每產出一個字，都是從一堆候選裡**抽**一個出來，不是去某個地方**查**一個標準答案。

所以「上次明明可以，這次就不行」不是你的錯覺，也不是你哪裡做錯了。它是這台機器的物理特性。

一旦接受這件事，後面才會理解為什麼這門課要你用**考卷**而不是用**單次感覺**來判斷有沒有變好。

> 一次跑得好，可能是運氣。十次都過，才是能力。

## 實驗二　不給資料，跟給資料

**要看到什麼**：它在不知道的時候會怎麼做。這個實驗的衝擊最大。

### 做法

**第一輪：什麼都不給。** 問一件它**不可能知道**的事。要具體到有名字、有數字。

好的問法：
- 「我們公司的 XX 專案，去年的結案報告裡提到哪三個風險？」
- 「我們部門的請購流程，超過多少金額要二簽？」
- 「客戶 A 上一季的續約條件是什麼？」

不好的問法：「什麼是專案管理」（這它真的知道）。

```
我問的是：__________________________________________

它回了什麼：


```

**它有說「我不知道」嗎？** 有　／　沒有，它編了一個看起來很合理的答案

**第二輪：把資料貼給它，再問一次同一題。**

```
這次的回答跟上次差在哪：


```

### 這說明什麼

如果它編了，注意一件事：**它不是在騙你。**

它接到的任務是「回答這個問題」，它就完成了這個任務。是我們沒告訴它「答不出來就要說答不出來」。

這叫幻覺，而它是這台機器的預設行為，不是故障。

### 帶得走的兩個動作

```
① 凡是需要事實的問題，就把資料一起給它，不要靠它記得
② 在你的指令裡加一句：「只根據我給的資料回答，
   資料裡沒有的就說『資料中無相關內容』，不要推測」
```

第二句話等一下在 Block C 會變成你 skill 裡的一條規則。

## 實驗三　思考深度是一個旋鈕

**要看到什麼**：「聰明」是可以調的，而且要付錢。

### 做法

同一題，跑兩次，把思考深度調到最低跟最高。

不同工具的名稱不一樣，找這類選項：思考模式、推理強度、reasoning、think、深度思考。找不到的話，用「快速模式」跟「進階模式」的切換也算。

| | 產出品質 | 等了多久 |
|---|---|---|
| 低 | | |
| 高 | | |

**差多少？** 差很多　／　有差但不大　／　幾乎沒差

### 這說明什麼

多數人以為只有「AI 聰不聰明」一個開關。實際上你隨時可以在**品質、速度、成本**之間換。

而且很重要的一點：**不是所有任務都值得開高。**

| 任務性質 | 建議 |
|---|---|
| 有標準答案、格式固定（分類、抽取欄位、翻譯） | 開低就好，開高是浪費 |
| 要推理、要權衡、要規劃 | 開高值得 |
| 你自己也不確定答案的 | 開高，然後自己驗 |

```
我的任務適合開哪一檔？為什麼：

  ________________________________________________
```

## 實驗四　三家工具跑同一題

**要看到什麼**：它們的個性不一樣。

### 做法

同一題，貼進三個不同家的對話工具。

### 記錄

| | 長度 | 語氣 | 有沒有自己加結構（標題、表格） | 有沒有反問你 |
|---|---|---|---|---|
| 工具 1 | | | | |
| 工具 2 | | | | |
| 工具 3 | | | | |

**哪一家的產出最接近你要的？** ____________

**為什麼？** ____________________________________

### 這說明什麼

要問的不是「哪一家最強」，是「哪一家適合我這個任務」。

強弱排名每三個月就洗一次，但「這家愛加表格、那家愛先反問」這種傾向相對穩定。而且對你來說，**適合比強重要**。

### 帶得走的動作

以後要換工具或評估新工具，不要看排行榜，用這個方法：

```
拿你最常做的那一題，在候選工具上各跑一次，比產出。
五分鐘，比看十篇評測準。
```

## 實驗五　算一次你剛剛的帳

**要看到什麼**：你剛剛花了多少錢。

### 先弄懂 token

模型不是按「字」計價，是按 **token**。token 是它把文字切開之後的最小單位。

概念上：

```
英文     ：大約 1 個 token ≈ 4 個字母，一個常用單字通常 1 個 token
中文     ：大約 1 個字 ≈ 1 到 2 個 token
```

**所以同樣一段話，中文比英文貴。** 這不是誰的問題，是切法造成的。

計費是**輸入加輸出**分開算，輸出通常比輸入貴好幾倍。

### 估一次

| 項目 | 你的估計 |
|---|---|
| 我的問題大約幾個字 | |
| 我貼的資料大約幾個字 | |
| 它回了大約幾個字 | |
| 換算 token（中文字數 × 1.5 概估） | 輸入 ______／輸出 ______ |

實際單價每家不同、每季會變，查當期價格表。**這裡的重點不是算出精確金額，是建立「這件事有成本」的體感。**

### 降本的三個槓桿

| 槓桿 | 做法 | 省多少 |
|---|---|---|
| **選對層級** | 簡單任務不要開高思考、不要用最貴的模型 | 最大 |
| **不塞廢話** | 「請仔細檢查」那類句子，每次都在付錢 | 中 |
| **重複的部分固定下來** | 每次都一樣的開頭，多數工具有快取機制，重複命中會便宜很多 | 視用量 |

第二點你在 Block B 會親手驗證一次。第三點正是 Block C 要你做的事——**把重複的東西沉澱成固定的資料夾，順便就省了錢。**
