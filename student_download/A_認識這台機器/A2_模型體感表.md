## 三張判斷表（帶回去用）

### 表一：這件事要不要給資料？

| 問題性質 | 做法 |
|---|---|
| 答案跟**你們公司**有關（人名、金額、規定、歷史） | 一定要給。不給它就會編 |
| 答案是**通用知識**（怎麼寫會議紀錄、什麼是 OKR） | 不用給 |
| 答案是**時效性的**（今年的法規、最近的價格） | 要給，或用有搜尋能力的工具 |
| 你**自己也不確定**的 | 給資料，並要求它標出處 |

一句話判斷：**這個答案，Google 得到嗎？** Google 不到的，你就得給它。

### 表二：思考深度開幾檔？

| 任務性質 | 開幾檔 | 理由 |
|---|---|---|
| 分類、抽取欄位、格式轉換、翻譯 | 低 | 有標準答案，開高只是多付錢 |
| 摘要、改寫、草稿 | 中 | |
| 規劃、權衡、找漏洞、比較方案 | 高 | 這種任務的價值就在推理 |
| 你自己也答不出來的 | 高，而且要自己驗 | |

### 表三：這件事該不該丟給 AI？

| 能不能檢查對錯？ | 做錯的代價 | 怎麼辦 |
|---|---|---|
| 可以，我說得出檢查標準 | 低 | **直接丟給它** |
| 可以，但代價高 | 高 | 丟給它，但**你要逐條檢查** |
| 我說不出檢查標準 | 任何 | **先別丟。** 先想清楚怎樣算做對 |

最後一列是這門課的入口。**說不出檢查標準的任務，不是 AI 做不了，是你還沒想清楚要什麼。**
