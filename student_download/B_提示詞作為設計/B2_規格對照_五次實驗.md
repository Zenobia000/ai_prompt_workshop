# B2　規格模糊 vs 規格明確 — 各跑五次

這是這門課唯一還有效的 before/after 對照。

先講為什麼要強調「還有效」。

過去的提示詞課都用「壞 prompt 得爛答案、好 prompt 得好答案」來做對比。那個對比現在垮了——你把隨便打的問題丟給現在的模型，它給你的東西通常不爛。

**所以差異不能看單次品質，要看變異度。**

---

## 實驗設計

同一個任務，兩個版本的規格，各跑五次，比通過率。

用你自己的任務，或用公版任務（`../公版任務/逐字稿A.md`）。

---

## 版本一：規格模糊

只寫①②，第③格留空或只寫一句。

```
【我的模糊版 prompt】




```

例如：「幫我把這份逐字稿整理成會議紀錄，要清楚易讀。」

---

## 版本二：規格明確

同樣的①②，但把第③格填滿。至少要有：

- **格式**：長什麼樣、分幾段、用表格還是條列
- **一定要有**：哪幾個欄位、哪些資訊少了就不算完成
- **長度**：幾字以內、幾頁以內
- **給誰看**：這決定語氣跟詳細程度
- **不能出現**：哪些東西一出現就是失敗

```
【我的明確版 prompt】




```

> 注意：明確版可能比模糊版**長**。這跟 B1 的砍字不衝突——
> 你砍掉的是形容詞，補上的是可核對的條件。

---

## 先訂通過標準

跑之前先寫，不然你會邊跑邊放寬標準。

**這次的產出要滿足哪三到五條，才算「可以交出去」？**

| # | 條件 | 能用 yes/no 回答嗎 |
|---|---|---|
| 1 | | ☐ |
| 2 | | ☐ |
| 3 | | ☐ |
| 4 | | ☐ |
| 5 | | ☐ |

右欄有任何一個打不了勾，回去改那一條。「要專業」不行，「沒有出現口語詞」可以。

## 讀結果

```
模糊版  ____/5   →   明確版  ____/5
```

### 你大概會看到的

**模糊版不是每次都爛。** 它可能有兩三次很好，甚至有一次比明確版還漂亮。

**問題是你不知道這次會拿到哪一種。**

那才是真正的成本：不是「產出很差」，是「你每次都要看過、都要修、都不敢直接交」。

### 如果兩版差不多

有兩種可能，值得分清楚：

| 可能 | 怎麼判斷 | 怎麼辦 |
|---|---|---|
| 你的通過標準太寬鬆 | 標準裡有「大致上」「差不多」這種詞 | 收緊，改成可核對的 |
| 這個任務本來就簡單 | 五條標準模糊版都輕鬆過 | **換一個更難的任務**。簡單任務不需要沉澱 |

第二種很重要。**不是所有任務都值得做成 skill。** 模糊版就五戰五勝的任務，你直接做就好，不用花兩小時沉澱它。

### 如果明確版反而更差

檢查你的第③格是不是寫成了「怎麼做」而不是「怎麼算做好」。

```
「請先讀過全文，再分段整理，最後檢查一次」  ← 這是步驟，是①
「每個行動項都要有具體人名和日期」          ← 這是驗收，是③
```

## 記下來，Block C 會用到

剛剛你為了寫明確版，被迫想出來的那三到五條通過標準——

**那就是你的驗收標準的第一版。**

```
把它們抄到這裡，明天要用：

1. ______________________________________________
2. ______________________________________________
3. ______________________________________________
4. ______________________________________________
5. ______________________________________________
```

你剛剛做的事，就是把腦袋裡的「認得出」寫成了「說得出」。只是還很粗糙，而且只有一個任務的一輪。

明天我們會用一週的真實使用紀錄，把它補完。
