# B1　三問、砍字、與框架的天花板

Block A 你摸清楚了這台機器怎麼運作。這一段處理的是：知道這些之後，指令該怎麼下。

---

## 先記住這張圖

所有提示詞框架，拆開來都只在問同樣三件事：

```
    ①  我要什麼？          ②  我給你什麼？        ③  怎麼算做好了？
        ↓                       ↓                       ↓
    現在的模型              現在的模型              它永遠猜不到
    你講得零零落落          你貼上去就好             只有你知道
    它也接得住                                      沒有框架幫你答
```

拿任何一個框架來對，都會摺進這三格：

| 框架 | ① 我要什麼 | ② 我給你什麼 | ③ 怎麼算做好了 |
|---|---|---|---|
| **STRIKE** | S 情境・T 任務・R 角色 | I 輸入 | K 驗收（只有一格） |
| **CTCO** | Context・Task | Context | Output（只講格式） |
| **CO-STAR** | Context・Objective・Style・Tone・Audience | — | Response（只講格式） |

看出來了嗎：它們都很會教①②，第③格一律最弱。而第③格剛好是模型唯一補不上的。

> **框架最弱的那格，就是你最貴的資產。**

---

```
【E 範例】
```

## 練習二　然後我們用它跑五次

不要改 prompt。把剛剛那個 STRIKE prompt 原封不動跑五次。

|---|---|
| 第 1 次 | |
| 第 2 次 | |
| 第 3 次 | |
| 第 4 次 | |
| 第 5 次 | |

**五次的產出，你都願意直接交出去嗎？** 全部都可以　／　___ 次可以

### 這說明什麼

框架幫你把①②講清楚了，這是它的功勞。

但五次還是五種結果，因為第③格你只填了一句話，而它需要的不只一句話。

> 框架幫你問問題，不幫你回答。它問得了①②，答不了③。

這不是 STRIKE 的問題，換任何框架都一樣。**這也是我們接下來一天半在做的事：把第③格填滿。**

## 練習三　砍字實驗

現在證明另一件事：你的 prompt 有一半是廢話。

### Step 1　拿出你平常在用的 prompt

用你平常最順手的一段。沒有的話用下面這段樣本（這是真實會出現的寫法）：

```
你是一位非常專業、經驗豐富的資深助理，擁有超過十年的行政經驗。
請你務必仔細地、認真地閱讀我接下來提供的這份會議逐字稿，
並且一步一步地思考，確保你完全理解會議的所有內容之後，
再幫我整理成一份清楚易讀的會議紀錄。
請務必不要遺漏任何重要的細節，也請確保內容的正確性。
如果有不確定的地方，請你再三確認。
謝謝你，你做得很好，我相信你可以完成得很棒。

逐字稿如下：
[貼上逐字稿]
```

**那就是第③格。圈起來，Block C 用得到。**

## 這一段的兩個結論

**一、你以為你在下指令，其實你有一半在安撫自己。**

而且這些話不是沒作用，是有反作用。模型必須把你寫的每一句都當成要遵守的指令，而且每一句你都在付錢（Block A 算過帳了）。

**二、但不要誤會 —— 不是「隨便打就好」。**

砍掉的是**廢話**，不是**要求**。

你等一下會發現，要補進去的東西比砍掉的還多。只是補的不是形容詞，是第③格：怎麼算做好了。

下一份練習單（`B2`）會讓你親眼看到，補了第③格之後差多少。
