## M0-M9 跟本工作坊的關係

`M0-M9_懶人包.md` 是「**怎麼做出一套可控的 AI 系統**」（工程向）。
本工作坊是「**怎麼把自己的工作沉澱成資產**」（工作流向）。

兩門課承重的重疊只有四塊，但那四塊是本工作坊的地基：

| M0–M9 的 | 在本工作坊的哪裡 |
|---|---|
| M2「廢話是模型必須服從的雜訊」 | 心法② 砍字實驗（單元 01） |
| M2「刪掉 Model Rule、只留 Business Rule」 | 心法⑦ 保存期限（單元 06） |
| M7「二元判準、同一份 dataset 比對」 | 心法⑥ 十題考卷（單元 05） |
| M9「他會來問你＝你的判斷還沒收斂」 | 心法⑥ 交棒測試（單元 05） |

M4（RAG）、M6（多 agent）、M8（provider 抽象）在本工作坊用不到。
**學員問起的話，明確告訴他那是另一門課，不要硬扯。**
